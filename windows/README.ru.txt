MULTIROUTE RESUME — НАСТРОЙКА ОКРУЖЕНИЯ WINDOWS

Извлеките полный готовый дистрибутив Windows в доступную для записи папку
с поддержкой прав доступа Windows, например пользовательскую папку на NTFS.
Первый запуск: Deploy-Windows.cmd. Затем: Start-Windows.cmd. Оба запуска
проверяют окружение и устанавливают недостающие компоненты перед открытием
приложения. В исходниках GitHub нет готовых JAR/сетевого EXE: сначала соберите
их либо скачайте готовый ZIP со страницы Releases.

Нужны Windows 11 x64 и встроенный Windows PowerShell 5.1. Проверяется полная
Java 17+ для x64 с модулями java.desktop, java.net.http, jdk.httpserver и java.xml.
JAVA_EXE задаёт конкретную Java; неправильное значение выводит ошибку.
При отсутствии этой переменной проверяются runtime/bin/java.exe, JAVA_HOME
и PATH. Если подходящей Java нет, автоматически скачивается закреплённый
официальный Temurin 21 JRE Windows x64, проверяется SHA-256 и архив безопасно
распаковывается в runtime этой программы. Для установки нужно минимум 512 МиБ
свободного места, дополнительно к месту для закачек. Старая приватная Java
сохраняется в runtime.previous-*. Системная Java не заменяется.

Npcap проверяется по службе драйвера и x64 DLL в System32/Npcap без открытия
устройства захвата. Если его нет, скачивается официальный установщик Npcap
1.89. Перед запуском проверяются закреплённая SHA-256, действительная подпись
Authenticode и издатель Nmap Software LLC. Затем Windows показывает UAC,
а установщик — лицензию и настройки. Прочитайте и примите его лицензию;
ограничения бесплатной редакции сохраняются. Драйвер не входит в дистрибутив
и не устанавливается скрытно. Отказ от UAC/лицензии останавливает установку.
Если нужна перезагрузка, перезагрузите Windows в удобное время и снова
откройте ярлык. Установленная, но остановленная служба не меняется скрытно:
будет выведена инструкция по проверке Npcap/перезагрузке.

Npcap в режиме «доступ только администраторам» может показать свой UAC при
проверке шлюзов. Java и интерфейс работают от обычного пользователя:
не запускайте всё приложение через «Запуск от имени администратора».
Подходящие уже установленные Java и Npcap работают без повторной загрузки ПО.
Интернет нужен для недостающего ПО и скачивания удалённых файлов.

Политика запуска PowerShell задаётся только для процесса ярлыка. Настройки
антивируса, постоянные политики, маршруты/IP ОС и системная Java не меняются.

Параметры сохраняются при передаче в приложение, например:
    Start-Windows.cmd --headless --port 8766
    Start-Windows.cmd --data-dir "C:\Users\your-user\MultiRoute data"

Полная инструкция: docs/ru.md. Для шлюзов необходимы проводной Ethernet,
одна локальная подсеть и свободный виртуальный IP приложения.

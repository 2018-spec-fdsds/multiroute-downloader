# Проверки MultiRoute Resume 3.0

Статус: **PASS_AVAILABLE_CHECKS**. Итоговый JAR: `8daba35dbb0893477fbdebd733daeac21095a01685255b77db2ec0c628b961fa`.
Проверяется сохранённый текущий код; производственные классы берутся из JAR,
отдельные папки тестов содержат только собственные тестовые классы.

## Проверено

- Добавление и удаление профилей до 32 шлюзов, отказ/rollback, сохранение выбора;
  кнопка добавления видна над списком, справка виртуального IP доступна.
- 11 сценариев интерфейса, 4 диалога, подсказка реального Swing-окна;
  пять языков, 842 строки каталога, 16066 проверок переводов/аргументов.
- Финальный localhost API, безопасная остановка своего экземпляра, журнал,
  выбор папки, Ctrl+V и скрытие MAC. Пользовательское приложение не остановлено.
- Очередь, приоритет, расписание, лимиты, batch/идемпотентность, SSE: 245 проверок.
- Реальные локальные целые файлы 73400351 и 1048647 байт: SHA-256 совпала;
  известная/неизвестная длина, промежуточный прогресс без двойного подсчёта.
- Разные ETag зеркал, отказ основного источника, контроль SHA-256 и хешей частей.
- Torrent с настоящей JNI libtorrent: пятый тестовый шлюз, пропуск/приоритет файла,
  ограниченная раздача только проверенных данных. Байты этих компонентов после
  проверок не изменились; прямое сравнение классов включено в отчёт.
- Настоящий минутный HTTP-тест: два зависших сегмента переданы другому шлюзу
  через **60925 мс**, старые писатели закрыты, итоговая SHA-256 совпала.
- 57 проверок FTP/FTPS/SFTP/WebDAV/Metalink/авторизации: TLS/SSH, диапазоны,
  защищённое хранилище, запрет утечки авторизации на другой origin и ошибок с секретами.
- Новый Windows-компонент и POSIX-компонент собраны, --self-test проходит
  без открытия сетевого захвата. Проверен сам включённый build_linux.sh.
- DNS: 67 проверок парсера, 12 сценариев Ethernet/lwIP на собственных пакетах:
  четыре шлюза, MAC/netif/виртуальный IP/UDP-порт, неверные ответы, кэш,
  тайм-аут и отмена. Объём повторных внутренних assertions не считается
  числом реальных DNS-запросов или физических испытаний.
- macOS bootstrap: 49 изолированных сценариев; Linux: 43, включая графические
  библиотеки и desktop-файлы. Для macOS JAR собственный HTTP-файл 1048603 байт
  собран и проверен на Windows; это проверка Java-кода, а не запуска на Mac.
- JAR платформ содержит одинаковые Java 17 классы, macOS включает JSch и
  нужные JNI, Windows EXE не включён в отдельный macOS архив.

## Границы

Физические роутеры, настоящий Mac/Apple SDK/BPF, Finder/Gatekeeper и установка
Java/системных пакетов/защищённого компонента на пользовательский компьютер
не проверены. Подпись/нотаризация macOS и IPv6 не реализованы. DNS использует
UDP с ограниченным кэшем; DNSSEC/DoH/TCP-повтор усечённых ответов отсутствуют.
Физическая инъекция мыши недоступна; проверено появление Swing-подсказки
по событиям собственного окна и визуально осмотрены собственные снимки.

Маршруты ОС и настройки антивируса не менялись. Старый отмеченный антивирусом
EXE не запускался. Новый EXE собран из текущих исходников и выполнен только
в автономном --self-test. Пользовательские загрузки и содержимое буфера
не использовались в испытаниях. Подробности и хеши: TEST-REPORT.json.

## 4.3.9 — الوظائف الحالية وFree وPro

يصف هذا الدليل MultiRoute Downloader 4.3.9 وإعداداته الحالية. نزّل حزمة منصتك من [التنزيلات المنشورة](https://github.com/2018-spec-fdsds/multiroute-downloader/releases/latest)، وتحقق من قيمتها SHA-256، ثم اتبع تعليمات التثبيت والأمان أدناه. تنطبق حدود Free وإمكانات Pro التالية على 4.3.9.

### حدود الترخيص والميزات

يتضمن Free التنزيل العادي لملف واحد والاستكمال المدعوم وكامل السرعة المتاحة وفحص السلامة وDNS المحمي وسرعات البوابات وحالتها المباشرة. لا يخفض عرض النطاق عمدًا. الحقوق الموقعة مستقلة؛ ترخيص Pro الجزئي يفعّل الحقوق المدرجة فيه فقط.

| الميزة | Free | مع الصلاحية في الترخيص | ID |
| --- | --- | --- | --- |
| البوابات المستخدمة معًا | ≤ 2 | ≤ 8 | <span dir="ltr">`extra_gateways`</span> |
| التنزيلات المتزامنة | ≤ 3 | ≤ 32 | <span dir="ltr">`extra_concurrent_downloads`</span> |
| ملفات تعريف المواقع | ≤ 3 | دون حصة ترخيص | <span dir="ltr">`extra_site_profiles`</span> |
| أولويات التنزيل | العادي فقط | قابلة للاختيار | <span dir="ltr">`download_priorities`</span> |
| أولويات البوابات | 0 | قابلة للاختيار | <span dir="ltr">`gateway_priorities`</span> |
| سجل البوابات وتقاريرها | غير مشمولة | مشمولة | <span dir="ltr">`gateway_statistics`</span> |
| تنزيلات / رفع جماعي | غير مشمولة | مشمولة | <span dir="ltr">`batch_downloads`</span> |
| واجهة API للتطبيقات الخارجية | غير مشمولة | مشمولة | <span dir="ltr">`automation_api`</span> |
| سمات إضافية | Graphite / System | جميع السمات | <span dir="ltr">`premium_appearance`</span> |

للدفعة، افتح **تنزيل جديد…** واختر **قائمة الروابط…** من صف الإجراءات الثابت أسفل تلك النافذة.

تُفعّل فقط الصلاحيات المضمنة في ترخيصك الموقّع. تبقى الملفات والملفات التعريفية محفوظة. تنتظر الملفات الإضافية في قائمة الانتظار، وتظل سرعة البوابات وحالتها الحالية متاحة. تستمر حدود سلامة التخزين.

حد البوابات يشمل المجموعة المشتركة للتنزيل والرفع دون مسار نظام إضافي. حد ثلاث مهام متزامنة يخص التنزيل لا الرفع، وتنتظر التنزيلات الأخرى في الطابور. يبقى حد الطابور الأقل الذي ضبطته ساريًا. لا تُحذف البوابات أو الملفات الشخصية أو التقدم أو الأولويات المحفوظة. حد الملفات الشخصية يخص إنشاء الجديد فقط؛ تبقى السابقة قابلة للاستخدام. يتطلب السجل/CSV حقه الخاص، بينما تبقى المؤشرات المباشرة مجانية. الجدولة متاحة؛ الأولويات غير العادية تحتاج حقها. تبقى الحدود التقنية للتخزين والمصدر.

يرتبط الترخيص الموقّع بمفتاح التثبيت لا بعنوان MAC أو IP أو الموجّه. لا تاريخ انتهاء؛ النطاق 4–4 يشمل 4.x. تغيير البوابات أو DHCP أو MAC التطبيق لا يحتاج إعادة تفعيل. قد يحتاج جهاز أو حساب أو ملف بيانات جديد إلى طلب جديد. هذا ليس وعدًا باستحالة تعديل الشيفرة أو ارتباط شامل بالعتاد.

### عنوان MAC للتطبيق

يستخدم MultiRoute عنوان MAC ثابتًا خاصًا به مع IP يدوي وDHCP دون تغيير عنوان بطاقة النظام. تُفحص التعارضات مع الأجهزة المرصودة والنسخ الأخرى؛ عدم الرد لا يثبت غياب الأجهزة المتوقفة. النطاق: عناوين MAC أحادية محلية الإدارة مع 46 بت عشوائيًا، وليس نطاق عناوين DHCP.

**تغيير MAC…** — استخدم الزر بعد إيقاف النقل النشط والمنتظر مؤقتًا أو إنهائه وانتهاء فحوص المجاميع المحلية. يفحص التطبيق العناوين المرصودة والإعلانات التعاونية لنسخ MultiRoute الأخرى. «لم يُكتشف تعارض» لا يضمن غياب جهاز مطفأ أو صامت يستخدم العنوان. يجب أن يختلف MAC التطبيق عن MAC المحوّل الفعلي؛ لا يتغير المحوّل أو مسارات النظام.

### المجموع الاختباري…

يُحفظ المرجع دون إعادة التنزيل أو تصفير التقدم. يُكتشف MD5 أو SHA-256 أو SHA-512 من 32 أو 64 أو 128 رقمًا سداسيًا. يُفحص الملف المجمّع بعد اكتمال التنزيل. احفظ المرجع ثم اختر تحقق الآن. يُقرأ الملف المحلي المكتمل، ويُبلغ عن الاختلاف دون إعادة تنزيله أو حذفه.

يستخدم الفحص النهائي آخر مرجع محفوظ. تعديله لا يمحو البايتات ولا يعيد النقل. يحافظ الفحص المحلي على الملف المكتمل ويعرض التطابق أو عدمه أو الخطأ منفصلًا عن اكتمال التنزيل. تبقى مراجع الناشر مستقلة. المجموع الكامل يخص ملف torrent واحدًا فقط. السلامة لا تثبت خلو المحتوى من الضرر؛ يُفضّل مرجع SHA-256/SHA-512 موثوق.

### الوصول إلى API في 4.3.9

تستخدم API المحلية JSON بترميز UTF-8 دون رمز API عادي. يتطلب التحكم الخارجي automation_api مع فحص الحقوق الأخرى أيضًا؛ فلا يكفي وحده للدفعات أو البوابات الإضافية. يحتفظ Free بتشخيص قراءة محدود ودورة حياة بمصادقة خاصة وجسر اختياري لرابط واحد من المتصفح. انظر [API](../API.ru.txt) و[OpenAPI](../openapi.yaml)؛ لا تعرض المنفذ للشبكة المحلية أو الإنترنت.


يخضع التطبيق الأصلي لـ[الترخيص 1.2](../LICENSE.txt): يجوز استخدام Free شخصيًا وداخل المؤسسات والأعمال، ويمكن لصاحب الحقوق عرض Pro مدفوع. لا يجوز للمتلقين الآخرين بيعه دون إذن منفصل. يتطلب OpenJDK GPLv2 مع Classpath Exception الإشعارات والمصادر الموافقة؛ تستخدم JNA ترخيص Apache-2.0 مع إشعاراته؛ وتحتفظ JLayer المنفصلة LGPL-2.1 بحقوق الاستبدال والتصحيح والمصادر. انظر [الشروط](../LICENSING.md) و[الكتالوج الكامل](../THIRD-PARTY-NOTICES.txt) وصفحة التراخيص.

يوفر مظهر System تباينًا واضحًا لنص الجداول والحقول وعناصر التحكم مع خلفية النظام؛ ويتضمن Free مظهري Graphite وSystem.

يظهر اسم الملف وحجمه الآن في عمودين منفصلين. يُرتب الحجم رقمياً وبشكل مستقل عن الاسم، وتُعرض شرطة للحجم غير المعروف. يبقى الاسم والمسار الكاملان متاحين في التلميح.

مرّر المؤشر فوق اسم الملف لعرض الاسم الكامل ومسار الحفظ وبروتوكول النقل وعنوان المصدر أو مساره المحلي. تُظهر مهام التورنت BitTorrent حتى إن فُتحت بياناتها الوصفية عبر HTTPS. يظهر عنوان المستودع، إن توفر، بعد عنوان الملف الفعلي. تُخفى بيانات الاعتماد المضمنة وقيم الاستعلام والأجزاء؛ وقد تبقى بصمة magnet العامة المعروفة ظاهرة. لا يتغير عنوان التنزيل المحفوظ أو حالة النقل.


### أولويات البوابات وتشخيص النقل في 4.3.9

في إعدادات الشبكة، عيّن أولوية كل بوابة بين **0 و1000**؛ تظهر القيمة أيضًا بجوار مؤشرها الرئيسي. يفضّل الرقم الأعلى البوابة للملفات الصغيرة أو النقل الكامل ويمنحها مقاطع متوازية أكثر للملفات الكبيرة. تواصل البوابات المختارة السليمة الأخرى المساعدة. تحافظ القيم المتساوية على ترتيب الاختيار؛ ويمكن لبوابة مختارة أخرى تولي العمل عند فشل البوابة المفضلة أو توقفها. هذا لا يضمن نسبة ثابتة بين السرعات.

يلزم الحق الموقّع المستقل <span dir="ltr">`gateway_priorities`</span>. لا يشمله حق أولوية المهام <span dir="ltr">`download_priorities`</span>. دون حق البوابات تكون الأولوية الفعلية للجميع 0 مع الاحتفاظ بالقيم المحفوظة. يمكن تغييرها أثناء التنزيل دون حذف الأجزاء المتحقق منها. لكل بوابة مختارة من عامل واحد إلى أربعة عمال متوازيين للمقاطع وبحد أقصى 32 عاملًا للمهمة.

تتيح الإعدادات اختيار عدد التنزيلات المتزامنة ضمن حد الترخيص وعدد محدود أو غير محدود من المحاولات التلقائية. تبقى الوقفات اليدوية مفعلة. تتيح قائمة النقر بالزر الأيمن إيقاف المهام المحددة المناسبة أو استئنافها ونسخ أسماء الملفات. يفتح النقر المزدوج المجلد فقط؛ وتوجد الخصائص والإحصاءات وسجل التنزيل الفردي في القائمة.

يبقى السجل الفردي متاحًا للملفات المكتملة. تفتح «الأخطاء والحلول» في الإعدادات دليلًا محليًا قابلًا للبحث يضم 25 موضوعًا بكل لغات الواجهة الاثنتي عشرة. يعرض مكان الحفظ والخصائص المساحة الحرة بالغيغابايت. يُبلغ عن امتلاء القرص المحلي صراحة، وتُحفظ الأجزاء ولا يتحول الخطأ إلى تكرار شبكي بلا نهاية. يبقى الجزء الأول المحفوظ ظاهرًا في التقدم عندما ينتظر مقطع صغير مستأنف بيانات جديدة.

### البيانات المتبقية للتنزيل · 4.3.9

أصبح جدول التنزيل يتضمن عمود **البيانات المتبقية**. يعرض عدد البايتات التي لم تُنزّل بعد بصورة مستقلة عن الوقت المتبقي المتوقع، ويدعم الفرز الرقمي. يحتسب التقدم المحفوظ والجاري ولا يقل عن الصفر؛ وتظهر شرطة عندما يكون الحجم الكلي غير معروف.

### بدء Mac وإعداد البوابات بصورة أكثر موثوقية · 4.3.9

يتعرف التشغيل الأصلي على Mac على المسار الافتراضي النسبي القديم، حتى عند غياب الشرطة المائلة الأولى، ويستخدم ملف إعدادات موجودًا تم التحقق منه أو مجلدًا افتراضيًا فارغًا يملكه المستخدم. تبقى المواقع المخصصة الملتبسة بحاجة إلى اختيار صريح بدل التخمين.

إذا فشل إعداد بوابة أو أُلغي، تتوقف البوابات الأخرى والفحوص الخلفية عن تكرار طلبات التفويض إلى أن تعيد إعداد الشبكة صراحة. قد يظل التشغيل الأول بصلاحيات مرتفعة بحاجة إلى تأكيد مسؤول macOS المعتاد لفتح جهاز Ethernet BPF.

يتعامل مكوّن شبكة Mac 4.3.2 مع إخفاء macOS لعنوان MAC الخاص بالمحوّل مع إبقاء فحوص حماية البطاقة الفعلية. يحتفظ التطبيق بعنوان MAC الخاص به ولا يغيّر مسارات النظام أو MAC البطاقة. تتوافق أيقونة Mac واسمه مع هوية MultiRoute على Windows. أغلق التطبيق قبل تحديث PKG. لا يزال اسم طالب التفويض في الحوار الحقيقي ونقل LAN/DHCP بحاجة إلى تحقق على جهاز فعلي؛ ويظل هذا النقل متطلبًا Ethernet سلكيًا.

**macOS:** `/Applications/MultiRoute Downloader.app` · `/Library/PrivilegedHelperTools/MultiRouteResume/4.3.2/{gateway-net,gateway-launch}`.

### ردود بوابات Mac مع عنوان يدوي · 4.3.9

صُحح إعداد الالتقاط في POSIX ليستخدم العنوان اليدوي للتطبيق وDHCP وضع استقبال الردود الموجهة إلى MAC الخاص بالتطبيق، كما كان في Windows. نجاح ping النظام يختبر اتصال الكمبيوتر نفسه ولا يثبت استقبال الردود على العنوان الافتراضي للتطبيق.

تحتفظ رسائل DHCP بصياغتها في اثنتي عشرة لغة بدل استبدالها بخطأ عام. لا يتغير سلوك التفويض الحالي: تعيد فحوص الشبكة العادية استخدام المكوّن المُجهز. لا تتغير نقاط API أو عناصر الواجهة أو مسارات النظام أو MAC البطاقة الفعلية. قد يظل أول وصول ذي صلاحيات إلى Ethernet BPF بحاجة إلى تأكيد المسؤول المعتاد.

يُصلح ذلك اختلافًا محددًا في وضع الالتقاط وليس جميع أسباب تعذر الوصول إلى البوابة. تبقى فحوص العنوان المتاح والشبكة الفرعية وإيجار وتعارض DHCP فعالة. لا تزال عمليات نقل Mac بعنوان يدوي بحاجة إلى تحقق على جهاز فعلي؛ ويظل Ethernet السلكي مطلوبًا.

## المظهر وأصوات الاكتمال

افتح **إعدادات المظهر** واختر من الأنماط التسعة: **Graphite** (الافتراضي)، **Nordic**، **StreamsStudio**، **Neon**، **Community**، **Chat**، **Studio**، **Rose**، **System**. يتضمن Free نمطي Graphite وSystem؛ وتتطلب الأنماط الأخرى إمكانية Pro المقابلة <span dir="ltr">`premium_appearance`</span>. يُحفظ الاختيار محليًا دون إعادة تشغيل التنزيلات. خيار **نوافذ وأزرار مستديرة** مستقل عن النمط. يمكن تدوير عناصر التحكم في الأنماط المختلفة، بينما يحدد نظام التشغيل الإطار الخارجي. قد تبقى النوافذ المكبّرة أو المثبّتة في Windows 11 مستطيلة؛ ويتحكم macOS وLinux أيضًا في حدود نوافذهما. يعرض رسم السرعة نشاط النقل، وتجمع بطاقات البوابات المختصرة إعداداتها في نافذة الشبكة.

أصوات الاكتمال **معطلة افتراضيًا**. فعّل المربع الرئيسي، ثم اختر بشكل مستقل التنبيه **بعد كل ملف** و**بعد جميع التنزيلات**. تتوفر أصوات **أجراس هادئة** و**بيانو** و**ماريمبا**، ويمكن معاينة لحن الملف ولحن النهاية. عند اكتمال جميع التنزيلات وتفعيل التنبيه العام، يُشغَّل للملف الأخير لحن النهاية فقط دون صوت ثانٍ متداخل. المهام المتوقفة مؤقتًا أو الفاشلة ليست تنزيلات مكتملة. لا تُعاد أصوات السجل القديم عند التشغيل أو تغيير الإعدادات. يعتمد سماعها أيضًا على مستوى صوت النظام ومخرج الصوت المحدد.

لاستخدام صوتك الخاص، اختر **لحن مخصص** وحدد ملفي **MP3 أو WAV** منفصلين لتنبيه الملف وتنبيه جميع التنزيلات. يجب ألا تتجاوز مدة كل مقطع **10 ثوانٍ**. يتحقق التطبيق من مدة الصوت بعد فك ترميزه، بدل الاعتماد على الامتداد أو البيانات الوصفية فقط. تُنسخ الملفات المقبولة إلى ملف التطبيق الشخصي المحلي، ويمكن نقل الملفات الأصلية بعد ذلك.

من **إعدادات المظهر** يمكنك إظهار **الصورة الرمزية لـMultiRoute** أو إخفاءها: عنصر اختياري مستقل على سطح المكتب، بشخصية رجل أو امرأة. اضبط الحجم بين **40–100%**، وانقر عليها نقرتين بزر الفأرة الأيسر لاستعادة نافذة التطبيق. تعتمد حركة المشي أو الركض على **سرعة التنزيل الإجمالية الفعلية**، وتتوقف عند الخمول. يعكس الكيس وملصقه **مجموع البايتات المتبقية المعروفة للتنزيلات النشطة**؛ ويُحتسب كل ملف مرة واحدة مهما تعددت البوابات، ولا يُختلق حجم متبقٍ للملفات مجهولة الحجم. يُحفظ خيار الإظهار، وتتوقف الحركة عند الإخفاء أو الخمول. هذا تمثيل بصري فقط؛ تبقى الملفات في المجلدات المختارة، ويظل العرض مستقلًا عن أصوات الاكتمال. الشخصيات رسومات أصلية مولّدة لا ترتبط بـCodex أو OpenAI.

المظهر والزوايا والأصوات والصورة الرمزية إعدادات محلية لواجهة سطح المكتب. لا تضيف نقاط وصول إلى واجهة API للتنزيل ولا تغيّر إعدادات النقل أو المجاميع الاختبارية أو أمان DNS.

## مسار الملف الشخصي عند التشغيل

يحفظ التطبيق المثبت مسارًا مطلقًا لمجلد البيانات، مستقلًا عن مجلد العمل عند تسجيل الدخول. يُحوَّل المسار النسبي المحفوظ إلى مسار مطلق فقط عند التعرّف على ملف شخصي موجود دون التباس. يبقى سجل التنزيل والإعدادات والأجزاء المحفوظة في مكانها. تظل المسارات النسبية للنسخة المحمولة والخيار الصريح <span dir="ltr">`--data-dir`</span> مدعومة وفق طريقة تشغيلها.

## التشغيل التلقائي

فعّل **التشغيل مع نظام التشغيل** بجوار إعدادات اللغة والمظهر. الخيار **معطّل افتراضيًا**. تفعيله يسجّل MultiRoute لبدء التشغيل عند تسجيل الدخول التالي إلى حسابك، وإيقافه يحذف إدخال التطبيق نفسه. يبدأ بعد تسجيل دخول المستخدم، وليس كخدمة نظام أو قبل الدخول. لا تتطلب إضافة الإدخال صلاحيات المسؤول.

يستخدم التشغيل التلقائي علبة النظام عند توفرها، وإلا يعرض نافذة عادية يمكن الوصول إليها. تبقى أولويات قائمة الانتظار وحالات الإيقاف المؤقت والجداول كما هي؛ ولا تُستأنف جميع التنزيلات المتوقفة قسرًا. افتح التطبيق يدويًا أولًا لإكمال التثبيت ومتطلبات مكوّن الشبكة. احتفظ بمسار التطبيق المسجّل، وكذلك Java والمكتبات عند الاستخدام المحمول. بعد النقل، عطّل التشغيل التلقائي ثم فعّله من الموقع الجديد. عطّله قبل إزالة التطبيق.

قد يعطّل نظام التشغيل أو سياسة سطح المكتب الإدخال المسجّل. في macOS، راجع **إعدادات النظام ← عام ← عناصر الدخول والملحقات** إذا طُلب إذن؛ إذن مكوّن الشبكة منفصل. وجود الإدخال لا يثبت نجاح التشغيل عند الدخول لاحقًا. فحوص ملفات الاختبار الخاصة لا تشمل إعادة تشغيل فعلية أو تسجيل خروج؛ راجع تقرير الإصدار المطابق.

إذا تعذّر فتح التطبيق، احذف **إدخاله الخاص فقط**:

- **Windows:** يحفظ التطبيق قيمة <span dir="ltr">`REG_SZ`</span> خاصة به باسم **MultiRoute Downloader** تحت <span dir="ltr">`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`</span>. يُفضّل إيقاف التشغيل التلقائي من داخل التطبيق. إن تعذّر فتحه، احذف **هذه القيمة فقط** عبر محرر السجل، مع الإبقاء على مفتاح Run والإدخالات الأخرى. إذا عطّلها النظام، استخدم **الإعدادات ← التطبيقات ← بدء التشغيل**؛ التطبيق لا يتجاوز هذا القرار. يحدّ Windows أمر البدء الكامل بـ260 حرفًا؛ إذا تجاوز الحد، استخدم مسارًا أقصر للتطبيق أو الملف الشخصي ثم سجّل من جديد.
- **macOS:** احذف <span dir="ltr">`~/Library/LaunchAgents/io.github.2018-spec-fdsds.multiroute-downloader.plist`</span>.
- **Linux:** احذف <span dir="ltr">`${XDG_CONFIG_HOME:-~/.config}/autostart/io.github.2018-spec-fdsds.multiroute-downloader.desktop`</span> من مجلد إعدادات XDG الفعلي. يلزم سطح مكتب رسومي يدعم تشغيل XDG التلقائي؛ هذا الخيار لا يثبّت خدمة systemd.

## إعدادات DNS

**تحقق من إصدار المثبّت وقيم SHA-256 المنشورة؛ وراجع NATIVE-INSTALLER-TESTS.json المطابق لنتائج التحقق من المنصات والملفات.**

افتح **الشبكة ← تحليل DNS**. الافتراضي هو **DNS عبر HTTPS ‏(DoH)، Cloudflare**. الإعداد خاص بـ MultiRoute ولا يغيّر DNS النظام أو المسارات أو عناوين IP للواجهات.

يدعم DoH نقل HTTP/2 المحدود عند اختياره عبر TLS ALPN وHTTP/1.1 عند التفاوض عليه. تُوثق توافقية المزوّد ونتائج البوابات الحقيقية في تقرير الإصدار النهائي المطابق.

- **DoH:** استعلامات DNS مشفرة عبر HTTPS من كل بوابة محددة، مع التحقق من شهادة TLS باسم مضيف URL.
- **DoT:** استعلامات DNS عبر TLS من كل بوابة محددة، بالمنفذ 853 افتراضياً، مع التحقق من اسم الخادم.
- **DNS النظام (الكمبيوتر):** استخدام سياسة DNS للكمبيوتر أو النظام أو VPN صراحةً. لا يُضمن مرور DNS عبر كل بوابة محددة، لكن اتصالات الملفات تحتفظ ببوابتها. لا يضمن هذا الوضع تشفير DNS.

اختر Cloudflare أو Quad9 أو Google أو **مخصص**. الإعدادات المسبقة ثابتة؛ يتيح الوضع المخصص تعديل URL/اسم الخادم والمنفذ وعناوين IPv4 العامة الرقمية للبدء. تسمح العناوين بالاتصال بالمزوّد دون تحليل اسمه أولاً عبر النظام. يتحقق DoH/DoT من سلسلة الثقة والاسم وSNI، ولا يرجع خفيةً إلى DNS غير مشفر أو DNS النظام. فشل الاستعلام الآمن ينهي تلك المحاولة. يجب أن يكون المزوّد متاحاً عبر البوابة المختارة.

عدّل المسودة وحدد البوابات ثم اضغط **اختبار DNS**. لا يحفظ الاختبار الإعداد، ويعرض لكل بوابة النتيجة والزمن وعناوين IPv4 العامة أو الخطأ. يبقى الفشل الجزئي ظاهراً. نجاح وضع النظام يفحص تحليل النظام ولا يثبت اتصال WAN المستقل لكل بوابة. **تطبيق إعدادات DNS** يتحقق ويحفظ، ويحدد رقم المراجعة المُعاد الإعداد المطبق. تحافظ تحديثات الحالة وتغييرات اللغة على المسودة غير المحفوظة والمؤشر والتمرير.

المهلة الكلية لكل استعلام 8 ثوانٍ وتشمل استعلامات DNSSEC المساعدة. تراعي TTL المعتمدة أيضًا انتهاء التوقيع؛ والتخزين الأصلي محدود بـ300 ثانية ومعزول حسب البوابة ومراجعة الإعدادات. تبقى TTL الصفرية وHTTP Age في DoH نافذتين. يتبع وضع النظام تخزين OS/JVM. تدعم وجهات الملفات IPv4 العامة؛ لا يضيف هذا الإصدار تحليل IPv6.

API: يقرأ <span dir="ltr">`GET /api/v1/network/dns`</span> الإعداد وحالة القراءة فقط؛ ويطبق <span dir="ltr">`PUT`</span> أو <span dir="ltr">`POST`</span> على المسار نفسه الإعداد. يختبر <span dir="ltr">`POST /api/v1/network/dns/test`</span> المسودة، ويسرد <span dir="ltr">`GET /api/v1/network/dns/providers`</span> الإعدادات المسبقة. أرسل حقول الإعداد فقط دون المراجعة والحالة من GET. [API](../API.ru.txt) · [OpenAPI](../openapi.yaml).

## التحقق المحلي من DNSSEC

في **الشبكة ← تحليل DNS ← التحقق من DNSSEC** اختر **التحقق من النطاقات الموقّعة** (افتراضيًا مع DoH/DoT)، أو **اشتراط إجابات DNSSEC آمنة**، أو **DNSSEC معطّل**. تتحقق Java محليًا باستخدام dnsjava ومراسي الثقة الجذرية المرفقة. لا تكفي علامة AD من المزوّد كدليل. يشفر DoH/DoT النقل، بينما يتحقق DNSSEC بصورة منفصلة من أصالة بيانات DNS.

يسمح **التحقق** بالإجابات الآمنة وغير المؤكدة الحماية؛ أما **الاشتراط** فيقبل الآمنة فقط. قد تعني الحماية غير المؤكدة تفويضًا غير موقّع موثّقًا أو خوارزميات غير مدعومة؛ راجع السبب. تُرفض النتائج غير الصالحة وغير المحددة عند تفعيل التحقق. يعطّل DNS النظام التحقق المحلي؛ والعودة إلى DoH/DoT تعيد السياسة السابقة. تغيير المزوّد يحفظها. التطبيق يحفظ الإعدادات، واختبار DNS يفحص المسودة غير المحفوظة.

تميز كل نتيجة بين <span dir="ltr">`secure`</span> و<span dir="ltr">`insecure`</span> و<span dir="ltr">`bogus`</span> و<span dir="ltr">`indeterminate`</span> و<span dir="ltr">`not_checked`</span>؛ وتظهر النتيجة المفقودة كغير متاحة. نجاح الاتصال لا يثبت أمان DNSSEC. لانتهاء التوقيع ونقص المفاتيح أو الأدلة وفشل الاستعلام والمهلة أسباب منفصلة. يجب ضبط الساعة بدقة. تستخدم الاستعلامات المساعدة البوابة نفسها والمهلة الكلية. لا يخفي DNSSEC الأسماء ولا يفحص محتوى الملفات.

في API يقبل <span dir="ltr">`dnssec`</span> القيم <span dir="ltr">`off`</span> و<span dir="ltr">`validate`</span> و<span dir="ltr">`require`</span>؛ ويقبل وضع النظام <span dir="ltr">`off`</span> فقط. الحقول <span dir="ltr">`dnssec_validation`</span> و<span dir="ltr">`dnssec_trust_anchors`</span> وحقول الاستعلام <span dir="ltr">`dnssec_status`</span> و<span dir="ltr">`dnssec_reason_code`</span> و<span dir="ltr">`dnssec_reason`</span> و<span dir="ltr">`dnssec_validated_ttl`</span> و<span dir="ltr">`dnssec_aux_queries`</span> للقراءة فقط؛ لا تُعد إرسالها عند الحفظ. راجع API/OpenAPI أعلاه و[DNSSEC](#التحقق-المحلي-من-dnssec-في-422).

**التعامل مع نطاقات HTTP:** إذا أعادت شبكة CDN مثل Civitai الحالة HTTP 200 لنطاق يبدأ من الصفر، يُفحص نطاق يبدأ بعد الصفر أيضاً. تقتصر قراءة الجزء الأول على حجمه؛ ويمكن متابعة البيانات المتوافقة المحفوظة من تنزيل تسلسلي على شكل أجزاء. عند وصول HTTP 200 مؤقتاً لنطاق لاحق، تُحفظ البيانات ويظل عامل البوابة متاحاً وتُعاد المحاولة بعد 2–30 ثانية. يميّز سجل النقل الدائم لكل بوابة بين حركة البيانات المستلمة والتقدم المحفوظ. [تشخيص النقل](transfer-diagnostics.en.md).

[تتضمن حزم 4.3.9](../downloads/v4.3.9/README.md) بيئة Java 21 خاصة. يعمل معالج Windows بالإنجليزية وينشئ اختصاراً على سطح المكتب؛ وتبقى Npcap مطلوبة بشكل منفصل. يستخدم macOS مكتبة libpcap الخاصة بالنظام. اتبع خطوات التثبيت وتأكيدات الأمان أدناه.

## الغرض وطريقة العمل

MultiRoute Downloader تطبيق سطح مكتب بلغة Java لتنزيل الملفات عبر عدة **بوابات إنترنت** موجودة على شبكة Ethernet المحلية نفسها. يمكن الجمع مثلاً بين اتصال سلكي وراوتر خلوي 4G/5G. تسحب البوابات المحددة الأجزاء من قائمة عمل مشتركة، فتستطيع البوابة الأسرع تنزيل أجزاء أكثر. إذا انقطع أحد الاتصالات، تواصل البوابات الأخرى العمل وتعود الأجزاء غير المكتملة إلى القائمة، مع الاحتفاظ بالبيانات التي اجتازت الفحص. يدعم التطبيق تنزيل مجموعات ملفات واستيراد قوائم روابط وواجهة API محلية للبرامج الأخرى.

تعتمد زيادة السرعة على استقلال سعة الاتصالات وحدود الخادم ودعم المصدر للاستئناف الآمن؛ ليست مضاعفة مضمونة بعدد البوابات. هذه واجهة سطح مكتب وليست واجهة ويب. اللغة الافتراضية للملف الجديد هي الإنجليزية، وتتوفر الروسية والألمانية والإسبانية والفرنسية والصينية والكورية والعربية والإيطالية واليابانية والهندية والفيتنامية أيضاً. يُحفظ الاختيار وتتبعه النصوص المسجلة والحالات والسجلات والتلميحات؛ قد تبقى رسالة خام من خادم أو مكتبة خارجية بلغتها الأصلية. لا تُترجم أسماء الملفات والمسارات وعناوين URL ومفاتيح JSON. تعرض الواجهة العربية عناصرها من اليمين إلى اليسار مع الحفاظ على قابلية قراءة البيانات التقنية.

<a name="application-virtual-ip"></a>

### لماذا يستخدم التطبيق عنوان IP افتراضيًا

**اختر بوابات MultiRoute دون تغيير اتصال التطبيقات الأخرى.** يستخدم التطبيق عنوان IPv4 محليًا خاصًا به وغير مستخدم لنقل الشبكة الداخلي. وبذلك يمكنه إنشاء اتصالات عبر البوابات المختارة بصورة مستقلة عن البوابة الافتراضية للكمبيوتر، دون تغيير عناوين محولات النظام أو جدول التوجيه أو البوابة الافتراضية لنظام التشغيل. يحتفظ المتصفح والبرامج الأخرى بإعدادات الشبكة المعتادة.

مثلًا، في شبكة LAN بعنوان <span dir="ltr">`192.168.1.0/24`</span> يحتفظ الكمبيوتر بعنوانه العادي <span dir="ltr">`192.168.1.x`</span>، ويمكن أن يستخدم MultiRoute العنوان الخالي <span dir="ltr">`192.168.1.70`</span>، بينما تمر التنزيلات عبر <span dir="ltr">`192.168.1.1`</span>–<span dir="ltr">`192.168.1.4`</span>. يجب أن يكون الكمبيوتر والعنوان الافتراضي والبوابات المختارة في شبكة IPv4 الفرعية الفعلية نفسها. افحص عنوانًا خاليًا وطبّقه في إعدادات شبكة التطبيق؛ لا تضفه يدويًا إلى محول نظام التشغيل. لا ينشئ هذا العنوان اتصال إنترنت إضافيًا؛ تأتي سعة النقل من أجهزة التوجيه ووصلاتها الخارجية.

#### اختيار العنوان وفحصه

1. افحص عنوان IPv4 وقناع الشبكة لمحول Ethernet في الكمبيوتر، واختر عنوان جهاز صالحًا ضمن الشبكة الفرعية نفسها. العنوان <span dir="ltr">`192.168.1.70`</span> مثال فقط؛ لا تستخدم عنوان الكمبيوتر نفسه أو أي بوابة أو عنوان الشبكة أو البث العام.
2. افتح إدارة جهاز التوجيه وتحقق من نطاق توزيع DHCP الفعلي. استخدم عنوانًا خارج التوزيع التلقائي أو احجزه/استبعده على خادم DHCP. إذا كانت عدة خوادم DHCP تخدم شبكة LAN نفسها، فيجب أن يمنع كل منها منح العنوان لجهاز آخر.
3. في MultiRoute اختر **فحص وتطبيق** للعنوان الافتراضي، ثم افحص البوابات. يتحقق التطبيق من الشبكة الفرعية ويفحص تعارض العنوان عبر ARP. غياب رد ARP يعني فقط أنه لم يُكتشف تعارض في تلك اللحظة؛ ولا يثبت أن العنوان خارج مجموعة DHCP أو يمنع منحه لاحقًا.

تتضمن حزم Windows/macOS بيئة Java 21 خاصة ومكوّن الشبكة المترجم. يحتاج Windows إلى برنامج تشغيل Npcap منفصل؛ لا يلزم تثبيت Java على حدة.

| المنصة | نظام التشغيل | المكوّنات |
| --- | --- | --- |
| Windows x64 | Windows 11 | Java 21 |
| Apple Silicon | macOS 26+ | Java 21 |
| Intel Mac | macOS 15+ | Java 21 |

يلزم محوّل Ethernet سلكي في شبكة IPv4 الفرعية نفسها مع جميع البوابات المختارة، وعنوان IPv4 افتراضي غير مستخدم، ومجلدات بيانات وتنزيل قابلة للكتابة ومساحة للملف والأجزاء المؤقتة. تعتمد زيادة السرعة على استقلال سعة اتصالات WAN وقدرة خادم المصدر. لا يلزم GPU.

يدعم التطبيق Linux، لكن مستودع التوزيعات هذا لا ينشر مثبّت Linux من السلسلة 4.x. لا تستخدم حزم Windows أو macOS على Linux.

قبل التحديث، انتظر انتهاء التنزيلات وعمليات الرفع والتحقق النهائي الجارية. ثم اخرج من قائمة علبة النظام وشغّل المثبّت الجديد الكامل. احتفظ بمجلد البيانات والملفات المنزلة والأجزاء المحفوظة.

### Windows

افتح EXE وأكمل تثبيت حساب المستخدم ثم شغّل التطبيق من قائمة ابدأ أو اختصار سطح المكتب. يفتح كتطبيق عادي، دون نافذة سكربت. نصوص المثبت الخاصة بنا بالإنجليزية، أما رسائل أمان النظام فتتبع لغة Windows.

يفحص التشغيل الأول وجود Npcap. عند غيابه، وافق داخل التطبيق على تنزيل النسخة الرسمية المحددة؛ يفحص SHA-256 وهوية الناشر Authenticode قبل فتح مثبت Npcap العادي. اقرأ الرخصة ووافق على طلب UAC المعتاد. أعد التشغيل إذا طُلب ثم افتح MultiRoute مجدداً. Npcap غير مضمن ولا يُثبت بصمت؛ يلزم الإنترنت لهذه الخطوة عند غيابه. قد يحتاج تثبيت AdminOnly إلى تصريح التقاط إضافي، مع إبقاء نافذة Java تحت حساب المستخدم العادي.

التطبيق والمثبت غير موقعين بهوية ناشر. إذا عرض SmartScreen ناشراً غير معروف، تحقّق من المصدر والهاش قبل أن تقرر استخدام «مزيد من المعلومات ← تشغيل على أي حال» إن توفر. اكتشاف برمجية ضارة مختلف عن هذا التحذير؛ لا توقف مضاد الفيروسات ولا تضف استثناء كتدبير تثبيت.

### macOS

اختر PKG المطابق للمعالج وافتحه في Apple Installer. وافق على تثبيت المكوّن المحمي وطلب المسؤول، ثم افتح <span dir="ltr">`/Applications/MultiRoute Downloader.app`</span> من Finder أو Spotlight أو Dock. لا تتطلب هذه الحزمة Terminal أو Command Line Tools أو Homebrew أو Java مستقلة.

عند الحاجة لفتح جهاز Ethernet BPF يظهر طلب مسؤول macOS العادي. يخفض المكوّن امتيازاته بعد فتح أجهزة الالتقاط، بينما تظل Java تحت المستخدم العادي. التطبيق والحزمة **غير موقعين بـ Developer ID ولم يخضعا للتوثيق notarization**. إذا عرض النظام مطوراً لا يمكن التحقق منه مع إمكانية استثناء، فتحقق أولاً من المصدر وSHA-256، ثم اتبع [تعليمات Apple](https://support.apple.com/en-us/102445): إعدادات النظام ← الخصوصية والأمان ← الفتح على أي حال، ثم فتح. قد تمنع سياسة جهاز مدار هذا الاستثناء.

تصريح التثبيت وتصريح المكوّن الشبكي واستثناء المطور غير المعروف تأكيدات منفصلة. اسمح عند الطلب بالوصول إلى **الشبكة المحلية** وإلى مجلد التنزيل الذي اخترته. لا تعطل Gatekeeper/SIP، ولا تزل علامات الحجر عن النظام كله، ولا تشغّل Java كاملة بصلاحية root. تحذير الملف التالف أو البرمجية الضارة ليس تحذير المطور العادي؛ توقف وتحقق من الملف.

<a name="4-البوابات-والعنوان-الافتراضي"></a>

## البوابات والعنوان الافتراضي

تتضمن أمثلة ملفات تعريف البوابات العناوين <span dir="ltr">`192.168.1.1`</span> و<span dir="ltr">`192.168.1.2`</span> و<span dir="ltr">`192.168.1.3`</span> و<span dir="ltr">`192.168.1.4`</span>. يمكن تعديل ملفات التعريف وإعداد **1–8** عناوين مختلفة. عدّلها بما يناسب شبكتك، وافحص البوابات واختر يدويًا ما تريد استخدامه؛ وجود أربعة ملفات تعريف لا يعني تفعيل البوابات الأربع. يتيح Free استخدام ما يصل إلى **بوابتين (2)** معًا، وتتيح إمكانية Pro المقابلة <span dir="ltr">`extra_gateways`</span> استخدام ما يصل إلى **8 بوابات**. يشمل الحد البوابات المستخدمة في التنزيل والرفع معًا. استخدام الكمبيوتر إحداها كبوابة افتراضية لا يضيف اتصال إنترنت آخر.

عنوان IPv4 الافتراضي للتطبيق هو <span dir="ltr">`192.168.1.70`</span>. افحصه وطبّقه في إعدادات الشبكة وتأكد من عدم استخدام جهاز آخر له، ثم احجزه خارج توزيع DHCP التلقائي. العنوان مخصص لنقل التطبيق الداخلي؛ **لا يُضاف إلى محول النظام ولا تتغير جداول توجيه النظام**، وتستمر البرامج الأخرى في اتصالها المعتاد. لا تضفه يدوياً إلى إعدادات الشبكة في نظام التشغيل. علامة الاستفهام والتلميحات تشرح الغرض.

افحص البوابات واختر واحدة أو عدة بوابات ضمن حد الترخيص. اختبار السرعة ينقل حتى **16 MiB أو 5 ثوانٍ**، وقد يضاف وقت إعداد الاتصال؛ هذا حد الاختبار فقط ولا يحد التنزيل العادي. عند عدم وجود رابط HTTP مباشر مناسب يُستخدم ملف اختبار Selectel.

يمكن إضافة أو حذف ملفات تعريف البوابات وتغيير بوابات المهمة أثناء التنزيل، ضمن حد الترخيص وبشرط بقاء بوابة واحدة على الأقل لكل مهمة غير مكتملة. لا تُحدد البوابة المضافة تلقائيًا للمهمات الموجودة. تغيير العنوان الافتراضي نفسه يتطلب إيقاف المهمات النشطة مؤقتًا. يُدار عنوان MAC الخاص بالتطبيق من إعدادات الشبكة؛ لا يتغير عنوان MAC للمحوّل الفعلي، وتُطبق شروط التوقف والفحص الموضحة في قسم MAC أعلاه.

<a name="5-إدارة-التنزيل-والواجهة-الحديثة"></a>

## إدارة التنزيل والواجهة الحديثة

1. الصق في حقل URL الطويل باستخدام Ctrl+V أو Cmd+V في macOS، أو زر اللصق. يمكن لصق magnet أو فتح ملف <span dir="ltr">`.torrent`</span>.
2. اختر مجلد الحفظ بنافذة النظام. الافتراضي في Windows هو <span dir="ltr">`%USERPROFILE%\Downloads`</span> وفي macOS/Linux هو <span dir="ltr">`~/Downloads`</span>؛ يبقى المجلد المختار يدوياً محفوظاً.
3. اختر البوابات واضغط بدء التنزيل بجانب الرابط. تتيح مستودعات Hugging Face وقوائم WebDAV وMetalink معاينة الملفات واختيارها. الاستيراد الجماعي يقبل رابطاً لكل سطر أو ملفاً نصياً.
4. راقب تقدم كل مهمة والوقت المنقضي والمتبقي والسرعة الكلية وسرعة وحجم كل بوابة والرسم الاختياري. أجزاء HTTP افتراضياً **20 MiB** ويمكن ضبطها 1–64 MiB. بعد **60 ثانية** دون بيانات يُلغى الجزء ويعود للمجموعة المشتركة لتسحبه بوابة أخرى. حجم قطع torrent من بياناته الوصفية.
5. تتوفر الإيقاف المؤقت والاستئناف والأولوية والحدود والجداول وتغيير مجلد المهمة المتوقفة. الافتراضي مهمتان نشطتان؛ تُستعاد المهمات التي كانت تعمل بحالة الإيقاف المؤقت بعد إعادة التشغيل. مشاركة torrent بعد الاكتمال متوقفة افتراضياً ويمكن تحديد وقتها ونسبتها.

تستخدم الواجهة FlatLaf مع أنماط المظهر الموضحة أعلاه، ويُحفظ الاختيار محليًا. يعرض الملخص جميع المهمات والنشطة والمكتملة والسرعة المجمعة لكل المهمات، بصرف النظر عن البحث أو المرشح. تبقى أشرطة التقدم الفردية والأعمدة بعرض اللوحة والفرز والبحث والتمرير مع حفظ موضع القراءة.

مرّر المؤشر فوق صف جارٍ أو مكتمل لعرض **اسم الملف كاملاً ومسار الحفظ المطلق**، حتى بعد الفرز أو التصفية. عنوان الملف المحدد يحمل التلميح نفسه، ويمكن نسخ المسار الكامل من قائمة النقر الأيمن. Ctrl+L/Cmd+L ينتقل للرابط، وCtrl+F/Cmd+F للبحث، وEscape يمسح البحث.

للمهمة المحددة تبويبا التفاصيل والسجل. يبقى موضع القراءة والنص المحدد عند التحديث أو تغيير اللغة؛ اختيار مهمة أخرى يفتح تقريرها من أوله. نافذة السجل العامة تفصل أحداث التطبيق عن سجل التنزيل. تُتابع الأحداث الجديدة عند نهاية السجل ولا يقفز العرض أثناء قراءة الأقدم.

إغلاق النافذة يترك التنزيل يعمل في علبة النظام. الأيقونة تعرض مجموع سرعات جميع المهمات حتى 10 Gbit/s، مع قيمة أدق في التلميح. اختر فتح التطبيق لإعادة النافذة، وخروج التطبيق للحفظ والإنهاء. إذا غابت العلبة يصغر إلى شريط المهام. **اخرج من العلبة قبل التحديث**.

لاختيار عدة صفوف تنزيل، انقر مع الضغط على **Ctrl** في Windows/Linux أو **Cmd** في macOS؛ وانقر مع **Shift** لاختيار نطاق. عندما يكون التركيز في الجدول، يحدد **Ctrl+A** أو **Cmd+A** جميع الصفوف الظاهرة فقط وفق البحث ومرشح الحالة. ينطبق إجراء الحذف على المجموعة المحددة كلها بتأكيد واحد. خيار حذف الملفات المكتملة والأجزاء المنزلة أيضًا **غير محدد افتراضيًا**، ولذلك يمكنك حذف سجلات القائمة فقط والاحتفاظ بالبيانات. حدده فقط إذا أردت حذف ملفات تلك المهام؛ تبقى الملفات الأخرى ومجلد الحفظ. تعرض النتيجة عدد السجلات المحذوفة. تبقى المهام التي تعذر حذفها في القائمة مع ملخص للأخطاء لتراجعها وتعيد المحاولة؛ ولا يتكرر حذف العناصر التي نجح حذفها. لا يمحو حذف المهام أو الملفات سجل التنزيل الدائم.

<a name="6-البروتوكولات-والوصول-والفحص"></a>

## البروتوكولات والوصول والفحص

| المصدر | السلوك والشروط |
| --- | --- |
| HTTP/HTTPS | تجزئة واستئناف عند توفر هوية ملف آمنة وbyte ranges؛ وإلا دفق كامل عبر بوابة واحدة يعاد من الصفر بعد الانقطاع |
| Hugging Face | روابط الملفات والمستودعات وحل Hub/Xet؛ المصادر الخاصة أو المقيدة تحتاج صلاحية المصدر المناسبة |
| FTP | EPSV/PASV السلبي؛ لا يشفر FTP العادي كلمات المرور أو البيانات |
| FTPS | TLS الصريح للتحكم والبيانات؛ FTPS الضمني غير مدعوم |
| SFTP | SSH مع بصمة SHA256 لمفتاح المضيف مثبتة ومتحقق منها بصورة مستقلة؛ لا تقبل مفاتيح مجهولة بصمت |
| WebDAV | قوائم HTTPS واختيار الملفات |
| Metalink | <span dir="ltr">`.meta4`</span> وSHA-256 موثوق ومرايا وهاشات قطع إن توفرت |
| Torrent/magnet | النقل عبر البوابات المختارة مع فحص قطع إلزامي وفق البيانات الوصفية واختيار الملفات والأولوية |

يمكن حفظ اسم المستخدم وكلمة المرور وBearer token وCookie أو رؤوس مسموحة ضمن إعدادات الوصول للمصدر بحسب origin دقيق مع تشفير محلي. هذه ليست رموزاً للراوتر؛ البوابات لا تحتاج token للتطبيق. لا تضع كلمة المرور في URL. تستخدم FTP/FTPS/SFTP دفق الملف الكامل دون مرجع SHA-256 أو SHA-512 موثوق منشور أو مُدخل يدوياً.

بعد التجميع تُحسب **MD5 وSHA-256 وSHA-512** بقراءة واحدة. يتعرف الحقل الرئيسي تلقائياً على 32/64/128 محرفاً ست عشرياً، ويمكن إدخال مراجع إضافية. يُبحث في رؤوس ملخص التمثيل الكامل وفي <span dir="ltr">`filename.md5`</span> و<span dir="ltr">`MD5SUMS`</span> و<span dir="ltr">`filename.sha256`</span> و<span dir="ltr">`SHA256SUMS`</span> و<span dir="ltr">`filename.sha512`</span> و<span dir="ltr">`SHA512SUMS`</span>، مع الاحتفاظ بفحص Hugging Face LFS وMetalink. ملخص استجابة HTTP الجزئية ليس ملخص الملف كله.

يجب تطابق كل المراجع المعروفة قبل نشر الملف النهائي. الفشل يبقي البيانات الجزئية. دون مرجع، القيمة محسوبة محلياً ولا تعني مطابقة مؤكدة للناشر. MD5 لاكتشاف التلف العرضي ولا يستبدل SHA-256/SHA-512 أو هوية الملف القوية. فحص قطع torrent مستقل عن هاش الملف الكامل؛ المرجع اليدوي الكامل يتطلب اختيار ملف واحد.

<a name="7-استخدام-api-من-تطبيق-آخر"></a>

## استخدام API من تطبيق آخر

أثناء التشغيل تتوفر API على <span dir="ltr">`http://127.0.0.1:8765/api/v1`</span>. الطلبات والردود JSON بترميز UTF-8، ومع الجسم استخدم <span dir="ltr">`Content-Type: application/json`</span>. لا يلزم API token لإنشاء المهمات وإدارتها محلياً؛ بيانات اعتماد المصدر منفصلة. الاتصال من الكمبيوتر نفسه فقط؛ لا تعرض المنفذ للشبكة أو الإنترنت. الخيار <span dir="ltr">`--headless`</span> للتشغيل دون نافذة. استخدم مشغل الحزمة الأصلية؛ أمثلة <span dir="ltr">`.cmd`</span> تخص portable.

تتطلب أمثلة API التالية إمكانية <span dir="ltr">`automation_api`</span>. يعرض المثال أربعة مسارات مفعّلة، لذلك يتطلب أيضًا إمكانية <span dir="ltr">`extra_gateways`</span> المناسبة؛ وهو لا يصف الاختيار الافتراضي في الواجهة. حدّد المسارات يدويًا وفق البوابات المتاحة وحد الترخيص: حتى 2 في Free أو حتى 8 مع إمكانية Pro المقابلة.

الفحص: <span dir="ltr">`GET /api/v1/health`</span> والرد المعتاد <span dir="ltr">`{"ok":true,"version":"4.3.9"}`</span>. اضبط الشبكة في الواجهة أولاً، أو أرسل إلى <span dir="ltr">`POST /api/v1/network`</span>:

<div dir="ltr">

```json
{
  "virtual_ip": "192.168.1.70",
  "gateways": ["192.168.1.1", "192.168.1.2", "192.168.1.3", "192.168.1.4"]
}
```

</div>
أرسل JSON التالي إلى <span dir="ltr">`POST /api/v1/jobs`</span> بعد استبدال الرابط والمجلد الفعلي على كمبيوتر التطبيق. مثال Linux هو <span dir="ltr">`/home/your-user/Downloads`</span> ومثال macOS هو <span dir="ltr">`/Users/your-user/Downloads`</span>. حدد <span dir="ltr">`routes`</span> صراحة؛ لا تنسخ API مربعات اختيار النافذة تلقائياً.

<div dir="ltr">

```json
{
  "url": "https://example.org/large-file.bin",
  "directory": "C:/Users/your-user/Downloads",
  "chunk_mb": 20,
  "routes": [
    {"type": "gateway", "gateway": "192.168.1.1", "enabled": true},
    {"type": "gateway", "gateway": "192.168.1.2", "enabled": true},
    {"type": "gateway", "gateway": "192.168.1.3", "enabled": true},
    {"type": "gateway", "gateway": "192.168.1.4", "enabled": true}
  ]
}
```

</div>
الحالة <span dir="ltr">`HTTP 201`</span> تعني إنشاء المهمة لا اكتمالها. احتفظ بـ <span dir="ltr">`id`</span> واطلب <span dir="ltr">`GET /api/v1/jobs/{id}`</span> حتى <span dir="ltr">`status: complete`</span> أو اقرأ <span dir="ltr">`error`</span> عند الفشل. وحدة <span dir="ltr">`speed_bps`</span> هي **بايت/ثانية**؛ اضرب في 8 واقسم على 1,000,000 للحصول على Mbit/s.

| HTTP | API |
| --- | --- |
| GET | <span dir="ltr">`/api/v1/health`</span> |
| GET / POST | <span dir="ltr">`/api/v1/jobs`</span> |
| GET | <span dir="ltr">`/api/v1/jobs/{id}`</span> |
| POST | <span dir="ltr">`/api/v1/jobs/{id}/pause`</span> |
| POST | <span dir="ltr">`/api/v1/jobs/{id}/resume`</span> |
| POST | <span dir="ltr">`/api/v1/jobs/{id}/routes`</span> |
| DELETE | <span dir="ltr">`/api/v1/jobs/{id}`</span> |
| GET / POST | <span dir="ltr">`/api/v1/network`</span> |
| POST | <span dir="ltr">`/api/v1/jobs/batch`</span> |
| GET / POST | <span dir="ltr">`/api/v1/queue`</span> |
| GET | <span dir="ltr">`/api/v1/events`</span> |

الإيقاف والاستئناف يقبلان <span dir="ltr">`{}`</span>. راجع [OpenAPI](../openapi.yaml) لجسم الحذف وحفظ الملفات افتراضياً و<span dir="ltr">`Idempotency-Key`</span> وقائمة الانتظار والاستيراد الجماعي وSSE والوصول والحدود. يمكن إرسال <span dir="ltr">`expected_md5`</span> و<span dir="ltr">`expected_sha256`</span> و<span dir="ltr">`expected_sha512`</span> عند الإنشاء، وتعرض النتائج <span dir="ltr">`md5`</span> و<span dir="ltr">`sha256`</span> و<span dir="ltr">`sha512`</span> و<span dir="ltr">`checksum_sources`</span> والتحذيرات. مفاتيح JSON والحالات ثابتة مهما تغيرت اللغة. [الأمثلة الموسعة](../API.ru.txt) باللغة الروسية.

مثال Python 3: استبدل الرابط التجريبي وأكمل إعداد الشبكة واترك التطبيق مفتوحاً. يحافظ UTF-8 على المسارات العربية أيضاً.

<div dir="ltr">

```python
import json
import urllib.request
from pathlib import Path

data = {
    "url": "https://example.org/large-file.bin",
    "directory": str(Path.home() / "Downloads"),
    "chunk_mb": 20,
    "routes": [
        {"type": "gateway", "gateway": f"192.168.1.{n}", "enabled": True}
        for n in range(1, 5)
    ],
}
request = urllib.request.Request(
    "http://127.0.0.1:8765/api/v1/jobs",
    data=json.dumps(data, ensure_ascii=False).encode("utf-8"),
    headers={"Content-Type": "application/json; charset=utf-8"},
    method="POST",
)
with urllib.request.urlopen(request, timeout=30) as response:
    job = json.loads(response.read().decode("utf-8"))
print(job["id"])
```

</div>

## التاريخ والبيانات والتحديث

| النظام | البيانات | التطبيق وJava |
| --- | --- | --- |
| Windows | <span dir="ltr">`%LOCALAPPDATA%\MultiRoute Downloader\data`</span> | <span dir="ltr">`%LOCALAPPDATA%\MultiRoute Downloader App`</span> |
| macOS | <span dir="ltr">`~/Library/Application Support/MultiRoute Downloader/data`</span> | <span dir="ltr">`/Applications/MultiRoute Downloader.app`</span> |
| Linux | <span dir="ltr">`~/.local/share/MultiRouteResume/data`</span> | <span dir="ltr">`~/.local/share/MultiRouteResume/`</span> |

الملف <span dir="ltr">`logs/downloads-history.jsonl`</span> هو JSON سطري UTF-8، و<span dir="ltr">`logs/downloads-history.log`</span> سجل مقروء بتاريخ ووقت. تضاف الأحداث بعد إعادة التشغيل ولا يُعاد كتابة الماضي عند تغيير اللغة أو حذف المهمة. يحافظ النص على لغة لحظة الكتابة، بينما تعرض الواجهة اللغة الحالية. تقرأ النافذة ذيلاً حتى 1,000 حدث/2 MiB فقط، ويظل السجل الكامل على القرص وينمو مع الاستخدام، فاحفظ أرشيفاً منفصلاً عند الحاجة. يسجل الأسماء والمسارات المطلقة دون URL المصدر أو كلمات المرور أو token؛ راجع المسارات قبل المشاركة.

تحتوي أحداث <span dir="ltr">`lifecycle_history`</span> على <span dir="ltr">`event_id`</span> و<span dir="ltr">`job_id`</span> و<span dir="ltr">`kind`</span> و<span dir="ltr">`time`</span> و<span dir="ltr">`filename`</span> و<span dir="ltr">`path`</span>؛ وقد تتضمن <span dir="ltr">`paths`</span> للتورنت أو <span dir="ltr">`reason`</span> للإيقاف (<span dir="ltr">`pause`</span> أو <span dir="ltr">`shutdown`</span> أو <span dir="ltr">`maintenance`</span>). الأنواع <span dir="ltr">`started`</span> و<span dir="ltr">`resumed`</span> و<span dir="ltr">`paused`</span> و<span dir="ltr">`completed`</span> و<span dir="ltr">`recovered`</span> و<span dir="ltr">`failed`</span>. الوقت ISO 8601 UTC، مثل <span dir="ltr">`2026-10-18T12:34:56.123Z`</span>، وفي السجل المقروء تاريخ محلي كامل ووقت وإزاحة UTC. الحقول الاختيارية <span dir="ltr">`first_started_at`</span> و<span dir="ltr">`last_resumed_at`</span> و<span dir="ltr">`completed_at`</span> تعكس البدء والاستئناف والاكتمال بعد الفحص والنشر كما شوهدت فعلاً. الانتظار ليس بدءاً؛ لا تُختلق أوقات لم تُرصد. <span dir="ltr">`recovered`</span> يعني التحقق الآن من ملف منشور موجود، ولا يثبت وقت اكتمال تنزيله.

اخرج من العلبة قبل ترقية حزمة كاملة واحتفظ بالبيانات والأجزاء للاستئناف. إزالة Windows من إعدادات التطبيقات المثبتة. حذف <span dir="ltr">`.app`</span> على Mac لا يزيل تلقائياً التاريخ أو المكوّن المحمي. لا تحذف مجلد التنزيل لمجرد إزالة البرنامج. أعد نشر Linux إذا نقلت مجلد التطبيق.

## الرخصة

يُسمح بالاستخدام المجاني للتطبيق الأصلي للأفراد والمؤسسات، بما في ذلك النشاط التجاري. يُمنع بيع التطبيق أو تحصيل رسم ترخيص أو توزيعه مقابل المال دون إذن منفصل. الرخصة الخاصة لا تمنح حقاً عاماً للتعديل أو إعادة التوزيع وليست رخصة مفتوحة المصدر معتمدة من OSI. النص الإنجليزي [LICENSE.txt](../LICENSE.txt) هو المرجع الملزم. يحتفظ FlatLaf ‏(Apache-2.0) والمكونات الأخرى برخصها. المالك: [2018-spec-fdsds](https://github.com/2018-spec-fdsds).

<a name="الاسم-والملفات-الشخصية-القديمة"></a>

## مجلدات الملفات الشخصية والمكوّن المحلي

توجد مجلدات البيانات ومواقع التطبيق في الجدول أعلاه. يمكن أيضًا العثور على ملف شخصي في <span dir="ltr">`%LOCALAPPDATA%\MultiRoute Resume\data`</span> أو <span dir="ltr">`~/Library/Application Support/MultiRoute Resume/data`</span>. إذا لم يوجد مجلد البيانات الافتراضي وتعرّف التطبيق بوضوح على ملف شخصي موجود في أحد هذه المواقع، فإنه يستخدمه دون نقل الملفات أو حذفها. لا تغيّر أسماء هذه المجلدات أثناء تشغيل التطبيق. يظل <span dir="ltr">`MultiRouteResume`</span> اسم مجلد المكوّن المحمي؛ وترتبط هوية التثبيت في Windows وهوية API الداخلية والمنفذ بالمكوّن المثبت. استخدم اختصار أو تطبيق MultiRoute Downloader المثبت لفتحه.

<a name="المواقع-المحفوظة-والرفع-ومعاينة-الأرشيف-40"></a>

## المواقع المحفوظة والرفع ومعاينة الأرشيف

افتح **ملفات تعريف المواقع…** لإنشاء ملف أو تعديله ثم اختره في **التنزيلات** أو **عمليات الرفع**. توجد البوابات وIP الافتراضي في **إعدادات الشبكة**. في **عمليات الرفع** أدخل **URL المجلد البعيد** واضغط **اختيار الملفات ورفعها…** لاختيار ملف محلي أو أكثر من منتقي النظام. تضيف الواجهة أسماء الملفات، أما API <span dir="ltr">`target_url`</span> فيحدد ملفًا بعيدًا كاملًا. لمعاينة أرشيف ألصق URL في الحقل الرئيسي واضغط **محتويات الأرشيف…**؛ لا يبدأ التنزيل.

يحفظ ملف الموقع الاسم وURL الأساسي ومجلد التنزيل المحلي والمجلد البعيد والبوابات. يدعم الوصول المجهول وHTTP Basic/Bearer/Cookie والرؤوس المخصصة وFTP وSFTP ببصمة SHA-256 للخادم تم التحقق منها مسبقًا. يمكن حفظ حسابات مستقلة للخادم نفسه. تتقدم المجلدات والبوابات المحددة صراحة على الافتراضيات؛ تُحل الروابط النسبية من URL الأساسي. تُشفّر الأسرار في <span dir="ltr">`site-profiles/vault.bin`</span> بالمفتاح المحلي <span dir="ltr">`site-profiles/key.bin`</span> وصلاحيات المالك فقط؛ من يسيطر على حسابك ومفتاحه يستطيع قراءتها. لا تعيد API الأسرار. تحتفظ الحقول الفارغة بها فقط إذا لم يتغير الأصل ونوع المصادقة؛ يستبدلها <span dir="ltr">`replace_credentials:true`</span>. لا ترسل إعادة توجيه HTTP إلى أصل آخر بيانات الملف. حذف الملف لا يحذف المهام أو الملفات المحلية/البعيدة؛ تحتفظ المهمة بارتباطها بالملف الأصلي ولا تبدّل الحساب؛ أعد إنشاءها بملف صالح عند الحاجة إذا حُذف الملف الأصلي.

يدعم الرفع وتصفح المجلدات البعيدة **FTP وFTPS الصريح وSFTP** عبر البوابات المختارة. اختر ملفًا محليًا عاديًا وURL كاملًا لملف بعيد (<span dir="ltr">`target_url`</span>) وليس مجلدًا فقط. يُستخدم ملف بعيد مؤقت ويمكن الاستكمال بعد مقارنة الجزء الموجود. يتطلب النجاح إعادة قراءة الملف البعيد كاملًا وفحص SHA-256؛ يحتاج الحساب صلاحيات **القراءة والكتابة وإعادة التسمية**. تستهلك القراءة الإضافية حركة بيانات. اختلاف البصمة أو رفض القراءة خطأ وليس نجاحًا. يستخدم الملف بوابة واحدة في كل مرة وتُوزع الملفات المستقلة للرفع بالتوازي. يمكن الانتقال إلى بوابة أخرى بعد حد الخمول؛ لا يُقسم رفع الملف الواحد بالتوازي. تبقى الحالة والإيقاف والاستكمال بعد إعادة التشغيل. حذف المهمة يحافظ على الملف المحلي والملفات البعيدة النهائية والمؤقتة.

الاستبدال معطل افتراضيًا. لا توفر جميع خوادم FTP/SFTP إعادة تسمية ذرية بشرط غياب الهدف؛ قد يغير عميل آخر الهدف أثناء النشر. نسّق الأهداف المشتركة. تصفح المجلد لا يرفع ولا يحذف الملفات.

تسرد معاينة **ZIP وTAR و7Z وRAR4 وRAR5** الأسماء والمسارات والأحجام وعلامات المجلد والتشفير دون فك أو تنفيذ. تتطلب بوابة مختارة ونطاقات بايت وETag أو Last-Modified ثابتًا. الحدود: 16 MiB للبيانات الوصفية و10,000 إدخال و60 ثانية؛ ذاكرة فك رؤوس 7z حتى 64 MiB. قد تكون القائمة مبتورة ولا تثبت سلامة المحتوى. حدد ترميز الأسماء الأصلي عند الخطأ. يمكن تقديم كلمة مرور غير محفوظة لرؤوس 7z المشفرة المدعومة. تُعرض رؤوس RAR المشفرة كغير مدعومة/تحتاج كلمة مرور؛ قد تظهر الأجزاء متعددة المجلدات جزئيًا.

تقبل API الحقل <span dir="ltr">`site_profile_id`</span> للتنزيل والرفع والتصفح والمعاينة. يعيد <span dir="ltr">`GET /api/v1/site-profiles`</span> الشكل <span dir="ltr">`{profiles:[...]}`</span> ويحفظ <span dir="ltr">`POST`</span> أو <span dir="ltr">`PUT`</span> كائنًا مسطحًا ويعيد بيانات عامة. يحذف <span dir="ltr">`DELETE /api/v1/site-profiles/{id}`</span> الملف التعريفي فقط. يقبل <span dir="ltr">`POST /api/v1/uploads`</span> الحقول <span dir="ltr">`local_path`</span> و<span dir="ltr">`target_url`</span> و<span dir="ltr">`routes`</span> و<span dir="ltr">`site_profile_id`</span> الاختياري و<span dir="ltr">`overwrite:false`</span> ويعيد HTTP 201. يعيد GET الشكل <span dir="ltr">`{uploads:[...]}`</span> وتتوفر GET/DELETE لكل مهمة وPOST <span dir="ltr">`/{id}/pause`</span> و<span dir="ltr">`/{id}/resume`</span>. يقبل <span dir="ltr">`POST /api/v1/remote/list`</span> الحقل <span dir="ltr">`url`</span> و<span dir="ltr">`route`</span>/<span dir="ltr">`routes`</span>؛ تقبل <span dir="ltr">`POST /api/v1/archives/preview`</span> أيضًا <span dir="ltr">`password`</span> و<span dir="ltr">`charset`</span> اختياريًا. راجع [openapi.yaml](../openapi.yaml). تخزن ملفات UTF-8 في <span dir="ltr">`data/uploads/`</span> معرّف الملف التعريفي دون كلمة المرور. لا تنشئ المعاينة مهمة تنزيل.

## جدولة التنزيل والأولوية

اضبط <span dir="ltr">`max_active_jobs`</span> بين 1–32 وحدود السرعة العامة/للبوابات والفترة اليومية (<span dir="ltr">`schedule_enabled`</span> و<span dir="ltr">`schedule_start`</span> و<span dir="ltr">`schedule_end`</span> بصيغة HH:mm) في إعدادات الطابور. يُستخدم توقيت الكمبيوتر المحلي ويظهر كـ<span dir="ltr">`schedule_timezone`</span>. يمكن عبور منتصف الليل؛ تساوي البداية والنهاية يعني اليوم كله. خارج الفترة تعود التنزيلات للطابور، وتبقى الموقوفة يدويًا موقوفة. ترتب <span dir="ltr">`priority`</span> من -100 إلى 100 المهام المنتظرة بالأعلى أولًا ثم تاريخ الإنشاء دون قطع المهام النشطة. <span dir="ltr">`start_after_ms`</span> أبكر وقت Unix بالملي ثانية و0 يلغي التأخير. تُحفظ الإعدادات للتنزيلات دون طابور الرفع المستقل. أبق التطبيق والكمبيوتر يعملان؛ لا يوجد إيقاظ للنظام. API: <span dir="ltr">`GET`</span>/<span dir="ltr">`PUT`</span>/<span dir="ltr">`POST /api/v1/queue`</span> و<span dir="ltr">`PUT`</span>/<span dir="ltr">`POST /api/v1/jobs/{id}/options`</span>.

## تكامل Chrome وEdge

افتح تكامل **Chrome / Edge** في التطبيق وفعّل إرسال الروابط وافتح مجلد الإضافة المرفق بالمثبّت. افتح <span dir="ltr">`chrome://extensions`</span> أو <span dir="ltr">`edge://extensions`</span>، وفعّل وضع المطوّر ثم اختر تحميل الإضافة غير المضغوطة من ذلك المجلد. لا تنقل المجلد المحدد.

يجب أن يعمل MultiRoute ولو في صينية النظام. أرسل الرابط من قائمته السياقية أو نافذة الإضافة. تُستخدم المجلدات والبوابات وملف الموقع الحالي وتبقى اختيارات المستودع/torrent عند الحاجة. المنفذ الافتراضي 8765؛ طابقه مع منفذ API إن تغيّر. يُرسل URL فقط دون cookies أو كلمات مرور ودون اعتراض التنزيلات الأخرى. اضبط وصول المصدر في التطبيق. إن طُلب إذن اتصال محلي فامنحه لهذه الإضافة المختارة فقط.

الجسر معطل افتراضيًا ويسمح فقط بالأصل <span dir="ltr">`chrome-extension://ljdklefabmaecjalfhjoicmgedmjjkbl`</span> على <span dir="ltr">`/api/v1/browser/status`</span> و<span dir="ltr">`/api/v1/browser/download`</span> دون تغيير قواعد API الأخرى. تعني HTTP 202 تسليم الرابط للواجهة لا اكتمال الملف. لا يفتح خادم headless وحده اختيارات سطح المكتب. احذف الإضافة من صفحة المتصفح أو عطّل التكامل لإيقاف التسليم.

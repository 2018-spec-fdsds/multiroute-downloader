## 1. الغرض وطريقة العمل

MultiRoute Resume تطبيق سطح مكتب بلغة Java لتنزيل الملفات عبر عدة **بوابات إنترنت** موجودة على شبكة Ethernet المحلية نفسها. يمكن الجمع مثلاً بين اتصال سلكي وراوتر خلوي 4G/5G. تسحب البوابات المحددة الأجزاء من قائمة عمل مشتركة، فتستطيع البوابة الأسرع تنزيل أجزاء أكثر. إذا انقطع أحد الاتصالات، تواصل البوابات الأخرى العمل وتعود الأجزاء غير المكتملة إلى القائمة، مع الاحتفاظ بالبيانات التي اجتازت الفحص. يدعم التطبيق تنزيل مجموعات ملفات واستيراد قوائم روابط وواجهة API محلية للبرامج الأخرى.

تعتمد زيادة السرعة على استقلال سعة الاتصالات وحدود الخادم ودعم المصدر للاستئناف الآمن؛ ليست مضاعفة مضمونة بعدد البوابات. هذه واجهة سطح مكتب وليست واجهة ويب. اللغة الافتراضية للملف الجديد هي الإنجليزية، وتتوفر الروسية والألمانية والإسبانية والفرنسية والصينية والكورية والعربية والإيطالية أيضاً. يُحفظ الاختيار وتتبعه النصوص المسجلة والحالات والسجلات والتلميحات؛ قد تبقى رسالة خام من خادم أو مكتبة خارجية بلغتها الأصلية. لا تُترجم أسماء الملفات والمسارات وعناوين URL ومفاتيح JSON. تعرض الواجهة العربية عناصرها من اليمين إلى اليسار مع الحفاظ على قابلية قراءة البيانات التقنية.

## 2. متطلبات الكمبيوتر والشبكة

| المنصة | النظام والمعالج | المكونات المطلوبة |
| --- | --- | --- |
| Windows | Windows 11 x64؛ لا توجد حزمة ARM64 | مثبت أصلي يتضمن Java 21 والمكوّن الشبكي x64؛ برنامج Npcap منفصل |
| Mac Apple Silicon | M1/M2/M3/M4 أو أحدث، macOS 26+ | حزمة arm64 تتضمن Java والمكوّن الشبكي المترجم |
| Mac Intel | x86_64، macOS 15+ | حزمة x86_64 تتضمن Java والمكوّن الشبكي |
| Linux | توزيعة glibc على x86_64 أو ARM64؛ torrent/magnet يحتاجان glibc 2.38+ | Java 17+ كاملة، sudo ومترجم C وbinutils وpkg-config وملفات تطوير libpcap؛ للواجهة X11 أو Wayland مع XWayland ومكتبات الخطوط |

يجب أن تتضمن Java الوحدات `java.desktop` و`java.net.http` و`jdk.httpserver` و`java.xml`، حتى مع `--headless`. لا يحتاج المثبت الأصلي لـ Windows/macOS إلى Java منفصلة. تنشر حزم portable ZIP 3.0 القديمة وLinux بيئة Java خاصة من مصادر رسمية عند الحاجة؛ لا تخلط ملفات منفردة من إصدارات مختلفة.

يلزم محول **Ethernet سلكي** على شبكة IPv4 الفرعية نفسها التي تضم كل البوابات المحددة، وأن تسمح كل بوابة للعنوان الافتراضي للتطبيق بالوصول إلى الإنترنت. تكوين يعتمد فقط على Wi-Fi أو VPN أو IPv6 ليس ضمن تكوينات هذا النقل المدعومة. يُنصح بذاكرة 4 GB للاستخدام المريح، لكنها ليست حداً مقاساً أو مفروضاً. لا حاجة إلى GPU أو CUDA أو نماذج ذكاء اصطناعي. يجب أن تكون مجلدات التطبيق والبيانات والتنزيل قابلة للكتابة. يفحص النشر وجود 512 MiB حرة على الأقل، إضافة إلى مساحة الملفات والأجزاء. احجز للتورنت مساحة إضافية للقطع الكاملة وحدود الملفات والوجهة والذاكرة المؤقتة.

تحتاج اللغة المختارة إلى خطوط مثبتة تغطي حروفها. على Linux محدود المكونات ثبّت حزم التوزيعة المناسبة، مثل Noto CJK للصينية والكورية وعائلة Noto عربية. تستخدم Java خطوط الاستبدال في النظام؛ لا يثبت التطبيق حزم خطوط ولا يضمها. قد تختلف تغطية الحروف بين الأجهزة.

## 3. التثبيت وتأكيدات الأمان

نزّل ملفاً واحداً مناسباً من [إصدار 4.0](https://github.com/2018-spec-fdsds/multiroute-resume/releases/tag/v4.0)، إذا كان مرفقاً بالإصدار، وقارن SHA-256 بالقيمة المنشورة:

- Windows: `MultiRoute-Resume-4.0-Windows-x64-Setup.exe`.
- Apple Silicon، macOS 26+: `MultiRoute-Resume-4.0-macOS-arm64.pkg`.
- Intel، macOS 15+: `MultiRoute-Resume-4.0-macOS-x86_64.pkg`.

### Windows

افتح EXE وأكمل تثبيت حساب المستخدم ثم شغّل التطبيق من قائمة ابدأ أو اختصار سطح المكتب. يفتح كتطبيق عادي، دون نافذة سكربت. نصوص المثبت الخاصة بنا بالإنجليزية، أما رسائل أمان النظام فتتبع لغة Windows.

يفحص التشغيل الأول وجود Npcap. عند غيابه، وافق داخل التطبيق على تنزيل النسخة الرسمية المحددة؛ يفحص SHA-256 وهوية الناشر Authenticode قبل فتح مثبت Npcap العادي. اقرأ الرخصة ووافق على طلب UAC المعتاد. أعد التشغيل إذا طُلب ثم افتح MultiRoute مجدداً. Npcap غير مضمن ولا يُثبت بصمت؛ يلزم الإنترنت لهذه الخطوة عند غيابه. قد يحتاج تثبيت AdminOnly إلى تصريح التقاط إضافي، مع إبقاء نافذة Java تحت حساب المستخدم العادي.

التطبيق والمثبت غير موقعين بهوية ناشر. إذا عرض SmartScreen ناشراً غير معروف، تحقّق من المصدر والهاش قبل أن تقرر استخدام «مزيد من المعلومات ← تشغيل على أي حال» إن توفر. اكتشاف برمجية ضارة مختلف عن هذا التحذير؛ لا توقف مضاد الفيروسات ولا تضف استثناء كتدبير تثبيت.

### macOS

اختر PKG المطابق للمعالج وافتحه في Apple Installer. وافق على تثبيت المكوّن المحمي وطلب المسؤول، ثم افتح `/Applications/MultiRoute Resume.app` من Finder أو Spotlight أو Dock. لا تتطلب هذه الحزمة Terminal أو Command Line Tools أو Homebrew أو Java مستقلة.

عند الحاجة لفتح جهاز Ethernet BPF يظهر طلب مسؤول macOS العادي. يخفض المكوّن امتيازاته بعد فتح أجهزة الالتقاط، بينما تظل Java تحت المستخدم العادي. التطبيق والحزمة **غير موقعين بـ Developer ID ولم يخضعا للتوثيق notarization**. إذا عرض النظام مطوراً لا يمكن التحقق منه مع إمكانية استثناء، فتحقق أولاً من المصدر وSHA-256، ثم اتبع [تعليمات Apple](https://support.apple.com/en-us/102445): إعدادات النظام ← الخصوصية والأمان ← الفتح على أي حال، ثم فتح. قد تمنع سياسة جهاز مدار هذا الاستثناء.

تصريح التثبيت وتصريح المكوّن الشبكي واستثناء المطور غير المعروف تأكيدات منفصلة. اسمح عند الطلب بالوصول إلى **الشبكة المحلية** وإلى مجلد التنزيل الذي اخترته. لا تعطل Gatekeeper/SIP، ولا تزل علامات الحجر عن النظام كله، ولا تشغّل Java كاملة بصلاحية root. تحذير الملف التالف أو البرمجية الضارة ليس تحذير المطور العادي؛ توقف وتحقق من الملف.

### Linux وحزم portable ZIP 3.0

فك حزمة ZIP كاملة. في Linux شغّل أولاً `bash ./Deploy-Linux.sh` ثم لاحقاً `bash ./Start-Linux.sh`. في Windows portable استخدم `Deploy-Windows.cmd` ثم `Start-Windows.cmd`، وفي macOS portable `Deploy-macOS.command` و`Start-macOS.command`. هذه حزم قديمة تحتفظ بالتشغيل بالسكربت، وليست مثبتات 4.0 الأصلية. قد يثبت Linux اعتماديات المترجم وlibpcap من التوزيعة، وقد يطلب macOS portable أدوات Apple وsudo. أبقِ جلسة الطرفية المطلوبة مفتوحة ولا تشغّل كل Java كـ root. Alpine/musl غير مضمن، والنشر لا يرقّي النظام ولا يستبدل glibc.

تتضمن الحزمة أدلة غير متصلة بتسع لغات. في Windows: `%LOCALAPPDATA%/MultiRoute Resume App/app/docs/`. في macOS اختر إظهار محتويات الحزمة ثم افتح `Contents/app/docs/ar.md`. تحتاج روابط الأدلة في المتصفح إلى الإنترنت.

## 4. البوابات والعنوان الافتراضي

البوابات الافتراضية الأربع هي `192.168.1.1` و`192.168.1.2` و`192.168.1.3` و`192.168.1.4` وتكون كلها محددة. يمكن تعديلها وإضافة **1–32** عنواناً مختلفاً. استخدام الكمبيوتر واحدة منها كبوابة افتراضية لا يعني وجود بوابة خامسة.

عنوان IPv4 الافتراضي للتطبيق هو `192.168.1.70`. افحصه وطبّقه في إعدادات الشبكة وتأكد من عدم استخدام جهاز آخر له، ثم احجزه خارج توزيع DHCP التلقائي. العنوان مخصص لنقل التطبيق الداخلي؛ **لا يُضاف إلى محول النظام ولا تتغير جداول توجيه النظام**، وتستمر البرامج الأخرى في اتصالها المعتاد. لا تضفه يدوياً إلى إعدادات الشبكة في نظام التشغيل. علامة الاستفهام والتلميحات تشرح الغرض.

افحص البوابات واختر واحدة أو عدة بوابات أو كلها. اختبار السرعة ينقل حتى **16 MiB أو 5 ثوانٍ**، وقد يضاف وقت إعداد الاتصال؛ هذا حد الاختبار فقط ولا يحد التنزيل العادي. عند عدم وجود رابط HTTP مباشر مناسب يُستخدم ملف اختبار Selectel.

يمكن إضافة أو حذف ملفات تعريف البوابات وتغيير بوابات المهمة أثناء التنزيل، بشرط بقاء بوابة واحدة على الأقل لكل مهمة غير مكتملة. لا تُحدد البوابة الجديدة تلقائياً للمهمات الموجودة. تغيير العنوان الافتراضي نفسه يتطلب إيقاف المهمات النشطة مؤقتاً. عناوين MAC مخفية من الواجهة.

## 5. إدارة التنزيل والواجهة الحديثة

1. الصق في حقل URL الطويل باستخدام Ctrl+V أو Cmd+V في macOS، أو زر اللصق. يمكن لصق magnet أو فتح ملف `.torrent`.
2. اختر مجلد الحفظ بنافذة النظام. الافتراضي في Windows هو `%USERPROFILE%\Downloads` وفي macOS/Linux هو `~/Downloads`؛ يبقى المجلد المختار يدوياً محفوظاً.
3. اختر البوابات واضغط بدء التنزيل بجانب الرابط. تتيح مستودعات Hugging Face وقوائم WebDAV وMetalink معاينة الملفات واختيارها. الاستيراد الجماعي يقبل رابطاً لكل سطر أو ملفاً نصياً.
4. راقب تقدم كل مهمة والوقت المنقضي والمتبقي والسرعة الكلية وسرعة وحجم كل بوابة والرسم الاختياري. أجزاء HTTP افتراضياً **20 MiB** ويمكن ضبطها 1–64 MiB. بعد **60 ثانية** دون بيانات يُلغى الجزء ويعود للمجموعة المشتركة لتسحبه بوابة أخرى. حجم قطع torrent من بياناته الوصفية.
5. تتوفر الإيقاف المؤقت والاستئناف والأولوية والحدود والجداول وتغيير مجلد المهمة المتوقفة. الافتراضي مهمتان نشطتان؛ تُستعاد المهمات التي كانت تعمل بحالة الإيقاف المؤقت بعد إعادة التشغيل. مشاركة torrent بعد الاكتمال متوقفة افتراضياً ويمكن تحديد وقتها ونسبتها.

تستخدم الواجهة FlatLaf مع سمات فاتحة وداكنة وسمات النظام ويُحفظ الاختيار. يعرض الملخص جميع المهمات والنشطة والمكتملة والسرعة المجمعة لكل المهمات، بصرف النظر عن البحث أو المرشح. تبقى أشرطة التقدم الفردية والأعمدة بعرض اللوحة والفرز والبحث والتمرير مع حفظ موضع القراءة.

مرّر المؤشر فوق صف جارٍ أو مكتمل لعرض **اسم الملف كاملاً ومسار الحفظ المطلق**، حتى بعد الفرز أو التصفية. عنوان الملف المحدد يحمل التلميح نفسه، ويمكن نسخ المسار الكامل من قائمة النقر الأيمن. Ctrl+L/Cmd+L ينتقل للرابط، وCtrl+F/Cmd+F للبحث، وEscape يمسح البحث.

للمهمة المحددة تبويبا التفاصيل والسجل. يبقى موضع القراءة والنص المحدد عند التحديث أو تغيير اللغة؛ اختيار مهمة أخرى يفتح تقريرها من أوله. نافذة السجل العامة تفصل أحداث التطبيق عن سجل التنزيل. تُتابع الأحداث الجديدة عند نهاية السجل ولا يقفز العرض أثناء قراءة الأقدم.

إغلاق النافذة يترك التنزيل يعمل في علبة النظام. الأيقونة تعرض مجموع سرعات جميع المهمات حتى 10 Gbit/s، مع قيمة أدق في التلميح. اختر فتح التطبيق لإعادة النافذة، وخروج التطبيق للحفظ والإنهاء. إذا غابت العلبة يصغر إلى شريط المهام. **اخرج من العلبة قبل التحديث**.

في حذف المهمة يكون خيار حذف الملفات **غير محدد افتراضياً**. يمكن إزالتها من القائمة مع الاحتفاظ بالملف المكتمل أو الجزئي؛ اختر حذف الملفات فقط إذا قصدت ذلك. لا يمحو حذف المهمة أو الملفات سجل التاريخ الدائم.

## 6. البروتوكولات والوصول والفحص

| المصدر | السلوك والشروط |
| --- | --- |
| HTTP/HTTPS | تجزئة واستئناف عند توفر هوية ملف آمنة وbyte ranges؛ وإلا دفق كامل عبر بوابة واحدة يعاد من الصفر بعد الانقطاع |
| Hugging Face | روابط الملفات والمستودعات وحل Hub/Xet؛ المصادر الخاصة أو المقيدة تحتاج صلاحية المصدر المناسبة |
| FTP | EPSV/PASV السلبي؛ لا يشفر FTP العادي كلمات المرور أو البيانات |
| FTPS | TLS الصريح للتحكم والبيانات؛ FTPS الضمني غير مدعوم |
| SFTP | SSH مع بصمة SHA256 لمفتاح المضيف مثبتة ومتحقق منها بصورة مستقلة؛ لا تقبل مفاتيح مجهولة بصمت |
| WebDAV | قوائم HTTPS واختيار الملفات |
| Metalink | `.meta4` وSHA-256 موثوق ومرايا وهاشات قطع إن توفرت |
| Torrent/magnet | النقل عبر البوابات المختارة مع فحص قطع إلزامي وفق البيانات الوصفية واختيار الملفات والأولوية |

يمكن حفظ اسم المستخدم وكلمة المرور وBearer token وCookie أو رؤوس مسموحة ضمن إعدادات الوصول للمصدر بحسب origin دقيق مع تشفير محلي. هذه ليست رموزاً للراوتر؛ البوابات لا تحتاج token للتطبيق. لا تضع كلمة المرور في URL. تستخدم FTP/FTPS/SFTP دفق الملف الكامل دون مرجع SHA-256 أو SHA-512 موثوق منشور أو مُدخل يدوياً.

بعد التجميع تُحسب **MD5 وSHA-256 وSHA-512** بقراءة واحدة. يتعرف الحقل الرئيسي تلقائياً على 32/64/128 محرفاً ست عشرياً، ويمكن إدخال مراجع إضافية. يُبحث في رؤوس ملخص التمثيل الكامل وفي `filename.md5` و`MD5SUMS` و`filename.sha256` و`SHA256SUMS` و`filename.sha512` و`SHA512SUMS`، مع الاحتفاظ بفحص Hugging Face LFS وMetalink. ملخص استجابة HTTP الجزئية ليس ملخص الملف كله.

يجب تطابق كل المراجع المعروفة قبل نشر الملف النهائي. الفشل يبقي البيانات الجزئية. دون مرجع، القيمة محسوبة محلياً ولا تعني مطابقة مؤكدة للناشر. MD5 لاكتشاف التلف العرضي ولا يستبدل SHA-256/SHA-512 أو هوية الملف القوية. فحص قطع torrent مستقل عن هاش الملف الكامل؛ المرجع اليدوي الكامل يتطلب اختيار ملف واحد.

## 7. استخدام API من تطبيق آخر

أثناء التشغيل تتوفر API على `http://127.0.0.1:8765/api/v1`. الطلبات والردود JSON بترميز UTF-8، ومع الجسم استخدم `Content-Type: application/json`. لا يلزم API token لإنشاء المهمات وإدارتها محلياً؛ بيانات اعتماد المصدر منفصلة. الاتصال من الكمبيوتر نفسه فقط؛ لا تعرض المنفذ للشبكة أو الإنترنت. الخيار `--headless` للتشغيل دون نافذة. استخدم مشغل الحزمة الأصلية؛ أمثلة `.cmd` تخص portable.

الفحص: `GET /api/v1/health` والرد المعتاد `{"ok":true,"version":"4.0"}`. اضبط الشبكة في الواجهة أولاً، أو أرسل إلى `POST /api/v1/network`:

```json
{
  "virtual_ip": "192.168.1.70",
  "gateways": ["192.168.1.1", "192.168.1.2", "192.168.1.3", "192.168.1.4"]
}
```

أرسل JSON التالي إلى `POST /api/v1/jobs` بعد استبدال الرابط والمجلد الفعلي على كمبيوتر التطبيق. مثال Linux هو `/home/your-user/Downloads` ومثال macOS هو `/Users/your-user/Downloads`. حدد `routes` صراحة؛ لا تنسخ API مربعات اختيار النافذة تلقائياً.

```json
{
  "url": "https://example.org/large-file.bin",
  "directory": "C:/Users/your-user/Downloads",
  "chunk_mb": 20,
  "routes": [
    {"type": "gateway", "gateway": "192.168.1.1", "enabled": true},
    {"type": "gateway", "gateway": "192.168.1.2", "enabled": true},
    {"type": "gateway", "gateway": "192.168.1.3", "enabled": true},
    {"type": "gateway", "gateway": "192.168.1.4", "enabled": true}
  ]
}
```

import json

}
request = urllib.request.Request(

with urllib.request.urlopen(request, timeout=30) as response:

## 8. التاريخ والبيانات والتحديث

| النظام | البيانات | التطبيق وJava |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\MultiRoute Resume\data` | `%LOCALAPPDATA%\MultiRoute Resume App` |
| macOS | `~/Library/Application Support/MultiRoute Resume/data` | `/Applications/MultiRoute Resume.app` |
| Linux | `~/.local/share/MultiRouteResume/data` | `~/.local/share/MultiRouteResume/` |

مكوّن macOS الأصلي هو `/Library/PrivilegedHelperTools/MultiRouteResume/4.0/gateway-net`. يستخدم Windows portable 3.0 مجلد `data/` بجانب المشغل مع إمكانية `data-location.config` أو `--data-dir`. Java الخاصة بـ Linux في `~/.local/share/MultiRouteResume/runtime` ومكوّنه المحمي في `/usr/local/libexec/MultiRouteResume/3.0/gateway-net`. ملفات التنزيل في الوجهة المختارة وقد تكون خارج هذه المسارات.

الملف `logs/downloads-history.jsonl` هو JSON سطري UTF-8، و`logs/downloads-history.log` سجل مقروء بتاريخ ووقت. تضاف الأحداث بعد إعادة التشغيل ولا يُعاد كتابة الماضي عند تغيير اللغة أو حذف المهمة. يحافظ النص على لغة لحظة الكتابة، بينما تعرض الواجهة اللغة الحالية. تقرأ النافذة ذيلاً حتى 1,000 حدث/2 MiB فقط، ويظل السجل الكامل على القرص وينمو مع الاستخدام، فاحفظ أرشيفاً منفصلاً عند الحاجة. يسجل الأسماء والمسارات المطلقة دون URL المصدر أو كلمات المرور أو token؛ راجع المسارات قبل المشاركة.

تحتوي أحداث `lifecycle_history` على `event_id` و`job_id` و`kind` و`time` و`filename` و`path`؛ وقد تتضمن `paths` للتورنت أو `reason` للإيقاف (`pause` أو `shutdown` أو `maintenance`). الأنواع `started` و`resumed` و`paused` و`completed` و`recovered` و`failed`. الوقت ISO 8601 UTC، مثل `2026-10-18T12:34:56.123Z`، وفي السجل المقروء تاريخ محلي كامل ووقت وإزاحة UTC. الحقول الاختيارية `first_started_at` و`last_resumed_at` و`completed_at` تعكس البدء والاستئناف والاكتمال بعد الفحص والنشر كما شوهدت فعلاً. الانتظار ليس بدءاً؛ لا تُخترع تواريخ المهمات القديمة. `recovered` فحص حالي لملف قديم منشور، لا معرفة وقت اكتماله السابق.

اخرج من العلبة قبل ترقية حزمة كاملة واحتفظ بالبيانات والأجزاء للاستئناف. إزالة Windows من إعدادات التطبيقات المثبتة. حذف `.app` على Mac لا يزيل تلقائياً التاريخ أو المكوّن المحمي. لا تحذف مجلد التنزيل لمجرد إزالة البرنامج. أعد نشر Linux إذا نقلت مجلد التطبيق.

## 9. استكشاف الأخطاء وحدود التحقق

- فشل البدء: تحقق من النظام/CPU والحزمة الكاملة ووحدات Java، وصحح `JAVA_EXE` أو `JAVA_HOME` إن عُيّنا خطأ. يبقى إصلاح قفل الملف المؤقت من 3.9 والتحقق من هوية النسخة السابقة.
- سرعة صفر: افحص Ethernet والشبكة الفرعية وخلو العنوان الافتراضي وصلاحية الإنترنت للمصدر والبوابة. نجاح اختبار السرعة لا يثبت نجاح كل تنزيل حقيقي.
- خطأ glibc أو مكتبة macOS للتورنت: استخدم إصدار النظام المطلوب، ولا تستبدل مكتبات النظام يدوياً.
- اختلاف مفتاح SFTP: تحقق مع مسؤول الخادم دون تعطيل فحص المفتاح.
- انشغال 8765 ببرنامج آخر: استخدم `--port 8766` ولا تُنهِ عملية لا تخص التطبيق؛ استبدال النسخة القديمة يتطلب هوية مؤكدة.
- نفاد المساحة/صلاحية المجلد: افحص مساحة الملف والقطع والذاكرة المؤقتة وأوقف مؤقتاً قبل تغيير الوجهة. استأنف المهمة القائمة بدلاً من إنشاء نسخة لنفس الهدف.

أرسل الإصدار والنظام/CPU والمرحلة والخطأ الدقيق، دون كلمات مرور أو token أو روابط خاصة أو بيانات شخصية. الاختبارات المتحكم بها على Windows/POSIX وMac CI وفحص الحزم لا تثبت تثبيت المستخدم الفعلي أو نوافذ Finder/Gatekeeper/BPF أو إنتاجية البوابات الفيزيائية وتحمل الأعطال. الحزم غير موقعة/موثقة؛ تعامل معها كـ **إصدار تجريبي**. افحص ملفاً صغيراً معروفاً عبر كل بوابة ثم المجموعة قبل الاعتماد على السرعة المجمعة.

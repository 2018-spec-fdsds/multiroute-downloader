The guides explain three separate confirmations: permission to open a trusted downloaded PKG/app, administrator authorization for installation or Ethernet capture, and Local Network access if macOS asks for it.

Launch **`/Applications/MultiRoute Downloader.app`** from Finder or Spotlight. Before an update, finish transfers and choose **Quit/Exit** from MultiRoute’s menu-bar/tray menu; closing the red window button can leave it running.

A healthy network component is reused for ordinary checks and speed tests. A changed application virtual IP, DHCP/MAC configuration or a new helper process can need authorization again. The app’s virtual address does not change OS routes or the physical adapter MAC. Enter a Mac administrator password only in its system dialog, never in licence or Hugging Face fields.

# MultiRoute Downloader 4.1.1

[Русский](4.1.1.ru.md) · [English guide](../en.md) · [Project overview](../../README.md) · [Installers](../../downloads/v4.1.1/)

This hotfix corrects gateway-bound DNS resolution and scrolling during automatic desktop refresh. The published 4.1 packages were built before these fixes; install the complete matching **4.1.1** package to update both Java and the native gateway component.

## DNS over the selected gateway

- When a UDP DNS query times out or a reply is truncated (`TC`), resolution can retry over TCP. Both paths use the **same selected gateway and application virtual IP**.
- The DNS operation has an overall **8-second** budget. It does not fall back to the operating system's resolver, another gateway or the computer's default Internet route.
- DNS-over-TCP results are recorded in the network log with translated presentation in the twelve supported languages. The persistent network-error journal introduced in 4.1 remains available for failures.
- This fixes the observed DNS-stage failure on gateway `192.168.1.1`, which previously surfaced as `Tunnel failed, got: 502`. It does not turn every HTTP or tunnel 502 into a successful connection.

Public IPv4 and Ethernet remain the supported gateway transport. DNSSEC, DoH, IPv6 and separate CNAME continuation queries remain unsupported. Application virtual-IP and OS routing behavior are unchanged: **system routes and interface addresses are not modified**.

## Scrolling stays where you leave it

Periodic status updates no longer move the surrounding form toward a text caret. The correction covers network settings and gateway lists, download and upload views, nested details and gateway metrics. Existing detail/history/log viewers retain their reading position; logs follow new entries when the reader was already at the bottom.

The UI regression uses real 900 ms refresh timers, 32 synthetic gateway rows, long messages, full layout changes, adding/removing rows, all twelve languages and tab roundtrips. It also checks keyboard navigation, scrollbar dragging, both log tabs and Unicode filenames. In the controlled Windows reproduction, the original 4.1 network viewport moved from 2789 to 320 pixels; with the correction it remained at 2789. No blanket scrolling or focus lock was added.

## Live four-gateway check

A Windows check completed a **100 MiB** file in about **32 seconds**, with all four configured gateways transferring data:

| Gateway | Transferred | 5 MiB test segments |
| --- | ---: | ---: |
| `192.168.1.1` | 10 MiB | 2 |
| `192.168.1.2` | 30 MiB | 6 |
| `192.168.1.3` | 20 MiB | 4 |
| `192.168.1.4` | 40 MiB | 8 |

The **5 MiB** setting was used for this short check. The application's default segment size remains **20 MiB**. These counters demonstrate participation in that transfer, not fixed shares, guaranteed throughput or a completed failover benchmark. No live macOS gateway transfer or DHCP change during an active download is claimed.

## Compatibility and installation

The local API retains `/api/v1`; its default address is `http://127.0.0.1:8765/api/v1`. `GET /health` reports version `4.1.1`. Existing jobs, verified segments, source-identity checks, profiles, uploads, scheduling, browser integration and MD5/SHA-256/SHA-512 verification retain their existing behavior. No intentional data-format or endpoint change is introduced by this hotfix.

Use a complete package rather than replacing one JAR or helper file. Exit the running application from its tray menu before installing an update. Java is included in the native installers:

| Platform | Installer |
| --- | --- |
| Windows 11 x64 | `MultiRoute-Downloader-4.1.1-Windows-x64-Setup.exe` |
| Apple Silicon, macOS 26+ | `MultiRoute-Downloader-4.1.1-macOS-arm64.pkg` |
| Intel, macOS 15+ | `MultiRoute-Downloader-4.1.1-macOS-x86_64.pkg` |

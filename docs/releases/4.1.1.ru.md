# MultiRoute Downloader 4.1.1

[English](4.1.1.en.md) · [Русская инструкция](../ru.md) · [Описание проекта](../../README.ru.md) · [Установщики](https://github.com/2018-spec-fdsds/multiroute-downloader/tree/main/downloads/v4.1.1)

Это исправление DNS через выбранный шлюз и прокрутки при автоматическом обновлении интерфейса. Опубликованные пакеты 4.1 были собраны **до этих исправлений**. Установите полный пакет **4.1.1**, чтобы обновить и Java-приложение, и сетевой компонент.

## DNS через выбранный шлюз

- После тайм-аута UDP или усечённого ответа DNS (`TC`) запрос может повторяться по TCP. Оба варианта используют **тот же выбранный шлюз и виртуальный IP приложения**.
- На всю операцию DNS выделяется **8 секунд**. Перехода на DNS операционной системы, другой шлюз или основной маршрут компьютера нет.
- Результаты DNS по TCP записываются в сетевой лог с отображением на двенадцати поддерживаемых языках. Постоянный журнал сетевых ошибок, добавленный в 4.1, продолжает сохранять сбои.
- Исправлен наблюдавшийся сбой DNS через `192.168.1.1`, который проявлялся как `Tunnel failed, got: 502`. Это не означает устранения любой возможной ошибки HTTP или туннеля 502.

Сетевой транспорт по-прежнему рассчитан на публичный IPv4 и Ethernet. DNSSEC, DoH, IPv6 и отдельные запросы продолжения CNAME не поддерживаются. Работа виртуального IP не меняется: **маршруты и адреса интерфейсов операционной системы не изменяются**.

## Прокрутка сохраняется

Периодическое обновление текста состояния больше не прокручивает всю форму к текстовому курсору. Исправление охватывает настройки сети и список шлюзов, загрузки и отправки, вложенные подробности и показатели шлюзов. Существующие панели подробностей, истории и журналов сохраняют место чтения; журналы следуют за новыми записями, когда пользователь уже находился внизу.

Проверка интерфейса использует реальные таймеры обновления 900 мс, 32 тестовых шлюза, длинные сообщения, полную переразметку, добавление/удаление строк, двенадцать языков и переключение вкладок. Также проверяются клавиатурная навигация, перетаскивание прокрутки, обе вкладки журнала и имена файлов Unicode. В контролируемом воспроизведении в Windows исходная 4.1 перемещала панель сети с 2789 до 320 пикселей; после исправления положение осталось 2789. Общая блокировка прокрутки или фокуса не вводилась.

## Реальная проверка четырёх шлюзов

В Windows завершена загрузка файла **100 МиБ** примерно за **32 секунды**. Все четыре настроенных шлюза передавали данные:

| Шлюз | Передано | Тестовых сегментов по 5 МиБ |
| --- | ---: | ---: |
| `192.168.1.1` | 10 МиБ | 2 |
| `192.168.1.2` | 30 МиБ | 6 |
| `192.168.1.3` | 20 МиБ | 4 |
| `192.168.1.4` | 40 МиБ | 8 |

Сегменты **5 МиБ** были выбраны для короткой проверки. Значение по умолчанию в приложении остаётся **20 МиБ**. Эти счётчики подтверждают участие шлюзов именно в этой передаче, а не постоянные доли, гарантированную скорость или завершённый тест отказоустойчивости. Реальная передача через шлюзы на Mac и смена DHCP во время активной загрузки ещё не проверялись.

## Совместимость и установка

Локальный API сохраняет `/api/v1` и адрес по умолчанию `http://127.0.0.1:8765/api/v1`. `GET /health` сообщает версию `4.1.1`. Существующие задания, проверенные части, контроль идентичности источника, профили, отправки, расписание, интеграция с браузерами и проверка MD5/SHA-256/SHA-512 сохраняют прежнее поведение. Это исправление не вводит намеренного изменения формата данных или API-маршрутов.

Обновляйте полный пакет, а не отдельный JAR или сетевой компонент. Перед установкой выйдите из работающего приложения через меню в трее. В установщики включена Java:

| Система | Установщик |
| --- | --- |
| Windows 11 x64 | `MultiRoute-Downloader-4.1.1-Windows-x64-Setup.exe` |
| Apple Silicon, macOS 26+ | `MultiRoute-Downloader-4.1.1-macOS-arm64.pkg` |
| Intel, macOS 15+ | `MultiRoute-Downloader-4.1.1-macOS-x86_64.pkg` |

Сопоставляйте контрольные суммы пакета и версию исходников с `NATIVE-INSTALLER-TESTS.json` рядом с файлами релиза. В отчёте указаны фактически выполненные сборки и проверки. Пакетам Mac нужна отдельная проверка сборки и содержимого; передача в Windows не подтверждает работу реальной сети Mac. Установщики не имеют подписи издателя; пакеты macOS не подписаны Developer ID и не нотарифицированы. Обычные подтверждения безопасности описаны в [инструкциях на разных языках](../ru.md).

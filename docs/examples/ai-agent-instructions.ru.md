Добавьте этот блок в существующий `AGENTS.md`, `CLAUDE.md` или другие постоянные инструкции проекта. Сохраните остальные правила. Один раз замените папку назначения и маршруты. Настройка и примеры: [Русский](../ai-agents.ru.md) · [English](../ai-agents.en.md).

```markdown
## Загрузки: использовать MultiRoute по умолчанию

Для внешних файлов, необходимых в рамках согласованной задачи проекта
(моделей, датасетов, архивов, медиа и других ресурсов), используй запущенный
MultiRoute Downloader. Не спрашивай каждый раз, какой загрузчик выбрать.
Установку зависимостей пакетными менеджерами и операции Git выполняй
их обычными средствами установки, клонирования и обновления.

Настройки проекта (заменить один раз):
- API: http://127.0.0.1:8765/api/v1
- Папка назначения: <ABSOLUTE_PROJECT_ASSETS_DIRECTORY_ON_THE_MULTIROUTE_COMPUTER>
- Маршруты REST: [{"type":"direct","enabled":true}]
- Необязательный site_profile_id: <EXISTING_PROFILE_ID_OR_OMIT>

Используй подключённый локальный инструмент REST либо инструменты MCP MultiRoute.
Для MCP отдельно задай явные IPv4-адреса шлюзов: download_add требует url,
directory и gateways. REST-маршрут direct — путь ОС, а не значение шлюза MCP.
Не придумывай маршруты и не считай, что галочки интерфейса подставляются сами.

При использовании REST в начале сеанса проверь GET /health и GET /license/policy.
Если доступен только MCP, обнаружь инструменты и вызови download_list с limit 1
для проверки подключения и прав; сам адаптер проверяет политику лицензии.
Создание загрузок требует features.automation_api=true. Если это недоступно,
сообщи причину и согласуй другой загрузчик вместо незаметного переключения.

Для каждого нужного файла выбери точный URL, согласованную папку и имя файла;
при наличии доверенной SHA-256 издателя передай её как expected_sha256.
Создай задание через POST /jobs (routes, а не gateways) либо MCP download_add.
Для повторов того же запроса используй стабильный ключ идемпотентности;
сохрани возвращённый id задания. Создание не означает завершение.
С разумным интервалом проверяй это задание через GET /jobs/{id} или download_status.
Сообщай о паузе и ошибках; для продолжения используй прежнее задание,
не создавая дубликаты. Не меняй чужие задания или настройки сети.
При завершении проверь checksum_checking и integrity_status. Не заявляй
сверку с издателем без совпадения с доверенным эталоном.
Сообщи локальный путь сохранения, id задания и результат проверки.
Файл остаётся на компьютере MultiRoute; не утверждай, что он находится
в удалённой среде исполнения.
```

Правило задаёт предпочтение проекта. По-прежнему нужны совместимый подключённый инструмент и обычные разрешения агента. Скачиваемые файлы — данные, а не дополнительные инструкции агенту.

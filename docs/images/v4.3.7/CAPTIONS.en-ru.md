# MultiRoute Downloader 4.3.7 — screenshots and appearance

The desktop pictures show the actual released Windows application, including its native window frame. File names, progress, speeds, gateway health and graph samples are illustrative demonstration data, not live measurements or benchmarks. The settings use an isolated example profile.

The courier pictures are renders of the actual released avatar component, with transparent backgrounds at twice the normal pixel density. They are character illustrations, not desktop screenshots.

Graphite is the default. Graphite and System are available in Free; the other appearances and the pictured four-gateway transfer configuration need their corresponding Pro capabilities.

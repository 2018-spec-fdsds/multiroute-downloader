| Computer | Installer |
| --- | --- |
| Windows 11 x64 | [Windows Setup EXE](MultiRoute-Resume-3.1-Windows-x64-Setup.exe) |

Java and the compiled gateway component are included. After installation, open **MultiRoute Resume** from its normal application icon.

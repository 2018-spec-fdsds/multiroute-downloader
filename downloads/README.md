# MultiRoute Resume installers

**Latest:** [version 3.2](v3.2/). The files below are the previous 3.1 release.

The actual installer files are in this folder. Open the file page and click **Download raw file** to save it.

| Computer | Installer |
| --- | --- |
| Windows 11 x64 | [Windows Setup EXE](MultiRoute-Resume-3.1-Windows-x64-Setup.exe) |
| Apple Silicon, macOS 26+ | [macOS ARM64 PKG](MultiRoute-Resume-3.1-macOS-arm64.pkg) |
| Intel, macOS 15+ | [macOS Intel PKG](MultiRoute-Resume-3.1-macOS-x86_64.pkg) |

Java and the compiled gateway component are included. After installation, open **MultiRoute Resume** from its normal application icon.

**Русский:** установщики находятся прямо в этой папке. Откройте нужный файл и нажмите **Download raw file**, чтобы скачать его. Java включена; после установки запускайте программу обычным значком.

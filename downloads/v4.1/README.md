# MultiRoute Downloader 4.1 installers

Persistent network-error history and validation of the actual LAN subnet. A computer IP change within the same subnet, mask and physical interface preserves the application's virtual IP. System routes remain unchanged.

Open a file and choose **Download raw file**, or use [Release 4.1](https://github.com/2018-spec-fdsds/multiroute-downloader/releases/tag/v4.1).

| Platform | File |

| Windows 11 x64 | [EXE](MultiRoute-Downloader-4.1-Windows-x64-Setup.exe) |
| Apple Silicon, macOS 26+ | [PKG](MultiRoute-Downloader-4.1-macOS-arm64.pkg) |
| Intel, macOS 15+ | [PKG](MultiRoute-Downloader-4.1-macOS-x86_64.pkg) |
| Chrome / Edge | [Extension ZIP](MultiRoute-Downloader-4.1-Chrome-Edge.zip) |

Java is included. Setup creates a desktop shortcut and uses English. Exit the running application through its tray menu before updating.

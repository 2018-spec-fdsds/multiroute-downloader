Open a file page and click **Download raw file**, or use [Release 4.0](https://github.com/2018-spec-fdsds/multiroute-downloader/releases/tag/v4.0). These are the actual installer binaries, identical to the release assets.

**New in 4.0:** daily/overnight scheduling, delayed starts and queue priorities, opt-in Chrome/Edge URL delivery, saved encrypted site profiles, verified FTP/FTPS/SFTP uploads and remote browsing, bounded ZIP/TAR/7Z/RAR previews, twelve interface languages, and a refreshed desktop with Light/Dark/System themes, queue totals and keyboard shortcuts. Hover over any download for its full filename and absolute destination; right-click to copy the path. The selected download has Details and History tabs. Dated start, continuation, pause, successful completion, recovery and failure events persist across restart in UTF-8 journals. Removing a job does not erase its history.

All existing download protocols, gateways, virtual IP, tests, batch import, source access, MD5/SHA-256/SHA-512, local API, tray and scroll fixes are retained. The interface does not change system routes.

Java and the FlatLaf theme dependency are included. Setup creates a desktop shortcut; our setup text remains English. **Before updating, use Exit application in the tray.**

**Русский:** обновлённый интерфейс со светлой, тёмной и системной темой, сводкой и горячими клавишами. Подсказки показывают полное имя и путь файла; меню правой кнопки копирует путь. История хранит даты начала, продолжений и завершения после перезапуска. Удаление задания не очищает историю. Прежние протоколы, шлюзы, виртуальный адрес, проверки, групповой импорт, локальный API и трей сохранены. Java включена. Перед установкой завершите приложение через меню трея.

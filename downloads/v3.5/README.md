# MultiRoute Resume 3.5 installers

Open a file page and click **Download raw file**, or use [Release 3.5](https://github.com/2018-spec-fdsds/multiroute-resume/releases/tag/v3.5). These are the actual installer binaries, identical to the release assets.

| Computer | Installer |
| --- | --- |
| Windows 11 x64 | [Windows EXE](MultiRoute-Resume-3.5-Windows-x64-Setup.exe) |
| Apple Silicon, macOS 26+ | [macOS ARM64 PKG](MultiRoute-Resume-3.5-macOS-arm64.pkg) |
| Intel, macOS 15+ | [macOS Intel PKG](MultiRoute-Resume-3.5-macOS-x86_64.pkg) |

**New in 3.5:** a progress bar for every download, columns filling the panel width, scrolling for long lists with a stable position on refresh, and a default download folder that follows the current user profile. A manually selected folder is retained.

MD5, SHA-256 and SHA-512 whole-file verification is retained. The main optional checksum field recognizes 32/64/128 hexadecimal characters automatically. Additional references are available in a collapsed section; all known references must match before publishing the completed file. The UI, tooltips and new diagnostics are available in five languages.

Java is included. Setup creates a desktop shortcut and our setup text is English. Closing the window keeps downloads running in the tray, with a transparent speed icon and black digits. **Before updating, use Exit application in the tray.**

**Русский:** отдельная полоса каждой загрузки, колонки на всю ширину, прокрутка с сохранением положения и папка загрузок текущего пользователя по умолчанию. Ручной выбор папки сохраняется. Версия 3.5 проверяет MD5, SHA-256 и SHA-512. Основное поле само распознаёт тип по 32/64/128 hex-символам; дополнительные эталоны находятся в раскрываемом разделе. До публикации файла должны совпасть все известные эталоны. Java включена. Перед обновлением завершите приложение через меню трея.

Интеграция Chrome / Edge находится в установленной программе; её папка открывается из настроек. При обновлении сохраняйте папку данных и скачанные части. Дождитесь завершения активных передач и проверки сумм перед заменой файлов программы.

Проверены метаданные установщика Windows и запуск настоящего приложения. Обе сборки macOS проверены на соответствующих Mac-серверах. Эти проверки не подтверждают работу DHCP и скорость передачи в физической локальной сети; пределы проверки записаны в отчёте.

Здесь распространяются скомпилированные установщики приложения и документация. Инструмент владельца для выдачи лицензий и закрытые ключи в релиз не входят.

Перед обновлением macOS через PKG выйдите из MultiRoute через меню трея. Установщик не заменяет используемое приложение и сам его не завершает. Защищённый сетевой компонент Mac имеет версию 4.3.2; первый привилегированный доступ к Ethernet BPF по-прежнему может потребовать обычного подтверждения администратора.

4.3.7 исправляет различие режима захвата POSIX для ручного адреса приложения и DHCP и сохраняет существующую диагностику DHCP на двенадцати языках. API и элементы интерфейса не меняются. Передачи Mac с ручным адресом не подтверждены проверкой на физическом оборудовании.

# MultiRoute Downloader 4.0.1 installers

Bulk selection and completed-download cleanup. Downloaded files are preserved unless you explicitly choose to delete them; this option starts unchecked.

Open a file and choose **Download raw file**, or use [Release 4.0.1](https://github.com/2018-spec-fdsds/multiroute-downloader/releases/tag/v4.0.1).
